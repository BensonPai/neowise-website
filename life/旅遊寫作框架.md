# 智慧喵 旅遊文章 寫作框架

> 開新對話要寫旅遊文章時，先讀這份即可掌握風格與結構。旅遊不做線性系列、不做目錄頁，跟投資理財修煉不同。

---

## 核心原則

- **只寫實際去過的地方**：真實體驗是最大優勢，也是這個部落格跟一般攻略最大的差別。
- **不做系列、不做目錄頁**：文章自由散落在「旅遊」分類（藍色標籤 `travel`），靠首頁篩選按鈕找。
- **想寫才寫**：沒有進度壓力，有實際旅行才寫。
- **分類固定為「旅遊」**：不另外加子分類；用標題自然標示類型即可。

---

## 每篇文章的五段式結構

依序涵蓋這五個面向（可依實際行程調整比重，但盡量都有）：

1. **行程規劃**：幾天幾夜、路線總覽（建議用一個行程總覽表），讓讀者一眼看懂節奏與動線。
2. **景點介紹**：每天／每個點在幹嘛、有什麼看頭、必做清單。
3. **文化體驗**：當地飲食、風俗、氛圍——這段最能寫出個人味道，跟一般攻略拉開差距。
4. **交通方式**：怎麼去、怎麼移動、票券建議（實用，也吃 SEO 的「地名＋交通」關鍵字）。
5. **旅遊感受**：真實心得、值不值得、適合誰去——這段是智慧喵的靈魂，別省略。

> 攻略部分（1、2、4）清楚好查；共鳴部分（3、5）有溫度。兩者兼顧。

---

## 文章類型（用標題自然標示，不用另做分類）

- **行程遊記**（主力）：「XX 幾天幾夜」，例：仙台 3 天 2 夜
- **主題攻略**：「XX 懶人包／XX 這樣玩」，例：關西交通票券怎麼選
- **旅遊技巧**：「XX 怎麼準備／XX 撇步」，例：第一次自由行準備清單（這類可呼應智慧喵的軟體品牌，如旅遊記帳）

## front-matter 範本

```yaml

author: "智慧喵"
category: "旅遊"
status: "approved"
cover_alt: "..."

  - file: "cover.jpg"        # 一律 jpg
    ...
```

## 寫作與配圖注意

- **內文圖要插進正文**（`![](assets/<slug>/xxx.jpg)`），別只留在 images 清單，否則不顯示。第一張自動當封面。
- 旅遊照片用**實拍最好**（jpg）；封面約 1200x630、內文約 1200x800，不超過 1600px 寬（產生器會自動縮）。
- 交通時刻、票券價格會過時，發布前建議快速對一下最新官方資訊。
- 語氣：親切、真實、有個人感受，跟智慧喵一貫口吻一致。結尾可用 🐾。

---

## 發文流程

1. 給地點與天數 → 依此框架在 `life/content/_drafts/` 產出 `.md`（`status` 直接 approved）。
2. 配圖放進 `life/assets/<slug>/`（缺圖可先發）。
3. 跑 `build-life.bat` 產生。
4. 確認沒問題後用 GitHub Desktop 上網站。

（旅遊不需更新任何目錄頁或前後連結，比投資理財系列單純。）
