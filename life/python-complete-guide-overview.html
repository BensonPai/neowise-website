【Python 教學】Python 是什麼、能做什麼？從零開始的學習地圖

智慧喵　•　2026-10-13

「我想學程式，大家都推薦 Python……但它到底能做什麼？從哪裡開始？」

如果你有這個疑問，這篇就是為你寫的。Python 幾乎是現在最多人推薦的入門語言，但一上網找教學，往往一堆術語砸過來，反而更不知道怎麼開始。這篇先不急著寫 code，而是帶你把整張地圖看清楚：Python 是什麼、能做哪些事、要裝什麼、以及這個系列會怎麼帶你學。

這是「Python 教學」系列的入口。後面我規劃的是一條循序漸進、重實用的路——不只教你語法，還會帶你用 Python 做它最擅長的事：自動化、爬蟲、資料處理。

如果你看過我的 C# 教學系列，會發現兩個系列結構類似。差別在：C# 偏扎實、工程導向；Python 偏好上手、重實用。兩個語言各有強項，學哪個都好，甚至都學也行。

一、Python 是什麼？

Python 是一種通用程式語言，1991 年問世，以「語法乾淨、好讀好寫」聞名。它的設計哲學就是「簡單優雅」——同樣一件事，Python 常常比其他語言用更少、更像白話的程式碼就能完成。

幾個它的特色，用白話說：

  • 好上手：語法接近英文，初學者負擔小，很適合當第一個語言。
  • 直譯式：寫完直接跑，不用像 C# 那樣先編譯，試錯很快。
  • 跨平台：Windows、Mac、Linux 都能跑。
  • 套件生態超強：幾乎你想做的事，都有現成的套件（library）可以用，站在巨人肩膀上。
關於縮排：Python 有個跟多數語言很不一樣的特色——它用縮排（空白）來表示程式區塊，而不是大括號 { }。這讓程式天生整齊，但也代表縮排不能亂，這點基礎篇會細談。

二、Python 能做什麼？

這是最多人好奇的地方。Python 的用途非常廣，這也是它紅的原因：

領域用的工具做出來的東西
自動化內建模組、腳本批次改檔名、整理資料夾、定時任務
網路爬蟲requests、BeautifulSoup自動抓網頁資料
資料分析pandas、matplotlib處理試算表、統計、畫圖表
人工智慧 / 機器學習TensorFlow、PyTorchAI 模型、深度學習
網站後端Django、Flask網站與 Web API
小工具內建 + 各種套件各種自用的小程式

對初學者特別有感的是前三項——自動化、爬蟲、資料分析。這些是「學一點就能馬上幫自己省事」的實用技能，也是這個系列會特別著墨的部分。

近年 AI 爆紅，Python 更是水漲船高——因為主流的 AI/機器學習工具幾乎都用 Python。想往 AI 方向發展，Python 幾乎是必備。

三、學 Python 要裝什麼？

好消息：全部免費，任何電腦都能開始。你需要兩樣東西。

1. Python 直譯器

這是讓 Python 程式能跑的核心，到 Python 官方網站下載安裝即可（Windows / Mac / Linux 都有）。安裝時 Windows 使用者記得勾「Add Python to PATH」（這點下一篇會提醒）。

2. 一個編輯器

  • VS Code：免費、輕量、裝個 Python 擴充套件就很好用，新手推薦這個。
  • PyCharm：專為 Python 設計的完整 IDE，功能強大，有免費社群版。
  • 另外還有 Jupyter Notebook，很適合資料分析時「一格一格跑」，之後資料處理篇會提到。
安裝 Python 時還會附帶一個超重要的工具 pip——它是「套件安裝器」，前面說的那些強大套件（requests、pandas…）都是用 pip 一行指令就裝好。環境篇會帶你認識它。

四、這個系列會帶你走到哪

我把 Python 的學習路徑分成五個階段，一階一階往上疊：

  1. 總覽（就是這篇）：先看懂全貌。
  2. 語法基礎：變數型別、流程控制、函式，以及 list、dict 等資料結構——寫任何 Python 程式的地基。
  3. 物件導向：類別與物件、繼承，學會用結構良好的方式組織程式。
  4. 實用應用：Python 的強項——檔案處理、網路爬蟲、自動化腳本、資料分析入門。這部分最「有感」，學一點就能幫自己做事。
  5. 實戰專案：把前面學到的整合成一個完整的小工具。

建議從頭照順序走。Python 雖然好上手，但地基（尤其資料結構）打穩了，後面的實用應用才學得輕鬆。

五、給初學者的三句真心話

  • 別怕看不懂，先動手跑。Python 試錯超快，讀十遍不如自己打一次、按下執行看結果。
  • 善用現成套件。Python 的精神就是「不要重造輪子」，很多事都有人寫好套件了，學會「找套件、用套件」跟學語法一樣重要。
  • 慢就是快。不急著追進度，每個概念真的懂了再往下，整體反而學得更穩。
