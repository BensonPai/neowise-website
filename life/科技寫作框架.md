# 智慧喵 科技文章 寫作框架

> 開新對話要寫科技文章時，先讀這份即可掌握範圍與風格。科技不做線性系列、不做目錄頁，比照旅遊/生活採輕量框架。

---

## 核心原則

- **分類固定為「科技」**（青藍色標籤 `tech`）：文章散落在「科技」分類，靠首頁篩選按鈕找。
- **不做系列、不做目錄頁**：想寫才寫，除非某主題確定要成系列（那再另議）。
- **定位偏硬派技術**：跟「生活」分類區隔——生活是健康美食/生活技巧/心情故事，科技是技術內容。
- **能自然帶軟體導流**：智慧喵自己開發軟體（進銷存、財務管理、股票投資分析、任務追蹤、iPhone 相片備份），寫到相關主題可自然帶到工具頁；不強求每篇都帶。

---

## 三個主題方向

1. **最新科技新知**：AI、新技術、產業趨勢、新產品發表的觀察與解讀。
2. **程式寫作**：開發心得、程式技巧、踩坑經驗、工具鏈、專案分享（可連結到自己開發的軟體）。
3. **資訊產品使用**：軟體/App/3C 的實測、評測、使用心得、推薦。

> 用標題自然標示主題即可，例如「【開發筆記】…」「【評測】…」，不強制格式。

---

## 結構（依主題彈性調整）

- **開場**：一個問題、痛點或情境切入（例如「你是不是也遇過 XXX」）。
- **主體**：
  - 新知類 → 是什麼、為什麼重要、影響是什麼。
  - 程式類 → 問題 → 做法/步驟/程式碼 → 結果與心得。
  - 評測類 → 功能、優缺點、適合誰、值不值得。
- **收尾**：一句心得或建議；相關時自然帶軟體或 YouTube，用 🐾 收。

---

## 寫作與配圖注意

- **內文圖要插進正文**（`![](assets/<slug>/xxx.jpg)`），別只留在 images 清單。第一張自動當封面。
- 程式碼可用 Markdown 的 ``` 區塊或行內 `code`（產生器支援）。
- 格式一律 jpg；封面約 1200x630、內文約 1200x800，不超過 1600px 寬（產生器會自動壓縮）。
- 含文字的示意圖/流程圖建議用 Canva；純氛圍圖用 AI 生圖（提示加「不要有任何文字」）。
- 語氣：專業但白話，跟智慧喵一貫口吻一致。

---

## 發文流程

1. 給主題 → 依此框架在 `life/content/_drafts/` 產出 `.md`（`status` 直接 approved）。
2. 配圖放進 `life/assets/<slug>/`（缺圖可先發）。
3. 跑 `build-life.bat` 產生。
4. 確認沒問題後用 GitHub Desktop 上網站。

（科技不需更新任何目錄頁或前後連結，比投資理財系列單純。）
