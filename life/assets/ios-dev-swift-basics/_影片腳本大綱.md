# 影片腳本大綱：Swift 語言基礎（iOS-2）

> 對應文章：ios-dev-swift-basics
> 影片定位：口說講解 + Xcode Playground 螢幕錄影（邊講邊打程式碼、即時看結果）。
> 建議長度：8~10 分鐘（程式教學可稍長）。

---

## 開場（20 秒）
- 鉤子：「環境裝好了，這支正式開始寫程式。今天學 Swift 語言基礎。」
- 先示範打開 Playground（螢幕）：歡迎畫面 New Project 旁箭頭 → 選 Playground → 空白範本；或 File → New → Playground。左邊寫碼、右邊即時看結果。
- 一句：Playground 是練功房，試語法用；做 App 才用完整專案。
- 文字版與可複製程式碼在說明欄文章連結。

## 段落一：變數與常數（1.5 分，Playground 實打）★
- var 可改、let 不可改，示範改 let 會報錯。
- 實務習慣：能用 let 就用 let（更安全）。

## 段落二：資料型別（1.5 分，Playground 實打）
- Int / Double / Bool / String。
- 型別推斷：不寫型別 Swift 也懂。
- 嚴格性：Int + Double 要轉型，示範報錯與修正。

## 段落三：流程控制（2 分，Playground 實打）★
- if / else if / else。
- switch（不用寫 break）。
- for 迴圈（1...5 範圍）、while 迴圈。
- 順帶示範字串內插 \(變數)。

## 段落四：函式（1.5 分，Playground 實打）
- greet 範例，逐一拆解 func / 名稱 / 參數 / 回傳型別。
- 為什麼要函式：包起來重複用、好維護。

## 段落五：可選型別 Optional（2~2.5 分，重點）★★
- 用「盒子」比喻：可能有值、可能空（nil）。
- String? 宣告、可以是 nil。
- if let 安全解包、?? 給預設值。
- 為什麼重要：避免當機。這段慢慢講。

## 收尾（30 秒）
- 練法：每個觀念親手打、可選型別多練、組一個小程式（輸入分數印等第）。
- 這步約 2~3 週，重點是手感不是讀完。
- 預告 iOS-3：用 SwiftUI 做第一個 App。
- CTA：訂閱、看文章、留言。🐾
