## 00:20 變數與常數

[螢幕] Playground 打出 var score 與 let name。

[旁白]
程式要處理資料，就需要地方存放。Swift 有兩個關鍵字。
第一個是 var，代表變數，它的值之後可以改。第二個是 let，代表常數，一旦設定就不能改。

[螢幕] 嘗試修改 let name，顯示紅色錯誤。

[旁白]
你看，我試著去改這個用 let 宣告的 name，Xcode 馬上就報錯了，因為常數不能改。
這裡給你一個實務習慣：能用 let 就用 let。這不是龜毛，把不該變的東西鎖成常數，可以讓編譯器幫你擋掉不小心改到的 bug，程式更安全。先預設用 let，真的需要改再換成 var。

## 01:50 資料型別與型別推斷

[螢幕] Playground 打出 Int / Double / Bool / String。

[旁白]
每個資料都有型別，表示它是什麼種類。常見的有：Int 整數、Double 小數、Bool 真假值、還有 String 文字。

[螢幕] 打出不寫型別的 let count = 5 等。

[旁白]
不過你會發現，很多時候我不寫型別，Swift 也懂。因為它會型別推斷，自己判斷這是整數還是文字。所以大部分時候你不用手動寫型別。

[螢幕] 示範 Int + Double 報錯，再用 Double() 轉型修正。

[旁白]
但要注意，Swift 對型別很嚴格。像這樣把一個整數跟一個小數直接相加，它會報錯。我得先把整數轉成 Double 才行。這種嚴格一開始覺得囉唆，但它能在你寫錯的當下就攔下來，而不是等 App 上線才出包。

## 03:20 流程控制

[螢幕] Playground 打出 if / else if / else。

[旁白]
接下來讓程式會做判斷。最基本的是 if else。這個例子裡，溫度大於等於 30 就說開冷氣，20 到 30 說天氣舒服，否則就說有點冷。

[螢幕] 打出 switch grade。

[旁白]
如果條件很多，用 switch 會更清楚。而且 Swift 的 switch 有個好處，每個情況不用自己寫 break，不會不小心掉下去執行下一個。

[螢幕] 打出 for 迴圈與 while 迴圈。

[旁白]
要重複做事就用迴圈。for 迴圈可以重複固定次數，這個 1 點點點 5 就是代表 1 到 5 的範圍。while 迴圈則是條件成立就一直做。
對了，你有看到這個反斜線加括號的寫法嗎？這叫字串內插，可以把變數的值直接塞進文字裡，非常常用。

## 05:20 函式

[螢幕] Playground 打出 greet 函式並呼叫。

[旁白]
函式可以把一段功能包起來，重複呼叫。我們來看這個打招呼的函式。
func 是宣告函式的關鍵字，greet 是名稱，括號裡的是參數，代表這個函式需要一個文字型別的名字，箭頭後面的 String 是回傳型別，表示它會吐回一段文字。
呼叫它、傳進智慧喵，它就回傳哈囉智慧喵。函式是組織程式的基本單位，把重複的邏輯包起來，程式會更好讀、好維護。

## 06:50 可選型別 Optional（重點，放慢）

[螢幕] 可選型別的盒子示意圖，或 Playground 打 String?。

[旁白]
最後這個觀念是 Swift 新手最容易卡、但也最重要的，我們慢慢講。
有時候一個變數可能有值，也可能沒有值。比如你查一個使用者的暱稱，他可能設過，也可能沒設。這個「可能沒有」的狀態，Swift 用可選型別來表示。
你可以把它想成一個盒子：盒子裡可能裝了東西，也可能是空的，空的狀態我們叫 nil。宣告的時候，在型別後面加一個問號，就代表這是可選的。

[螢幕] 打出 if let 解包。

[旁白]
那要怎麼安全地打開盒子、拿出裡面的值呢？最常用的做法是 if let。如果盒子裡有值，就把它取出來用；如果是空的，就走 else。

[螢幕] 打出 ?? 預設值。

[旁白]
還有一個很實用的雙問號，叫預設值運算子。盒子有值就用它，是空的就用後面給的備用值，像這裡就是沒有暱稱時顯示訪客。
為什麼 Swift 要搞這一套？因為「以為有值、結果是空的」是 App 當機最常見的原因之一。Swift 逼你在寫的時候就處理好，用一點前期的麻煩，換掉大量上線後的當機。一開始不習慣，但寫久了你會感謝它。
