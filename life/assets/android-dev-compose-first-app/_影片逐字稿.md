## 00:20 Composable

[螢幕] 新建 Compose 專案，看 @Composable 函式與預覽。

[旁白]
在 Compose 裡，畫面上的每個東西都是一個 Composable 函式，一個標了 @Composable 的函式，用來描述這塊畫面長怎樣。
Android Studio 會給你類似這段。@Composable 標記這是可組合的 UI 函式，它其實就是個普通的 Kotlin 函式，只是它畫的是畫面，這個 Text 就是顯示文字的元件。右邊有預覽，改程式碼即時看，跟 SwiftUI 一樣好用。
對照一下，Composable 函式就相當於 SwiftUI 的 View，本質都是描述畫面。
先講一件很重要的事，等一下你貼範例可能會看到一堆紅字，說 Unresolved reference，比如找不到 Button、Color、sp。別緊張，那不是程式錯，是缺 import。Compose 的元件分散在不同套件，用之前要先 import。你不用背，把游標點在紅字上按 Alt Enter，Mac 是 Option Enter，選 Import，它就自動幫你加。或者去設定裡開自動匯入，打字時它就順手幫你補。

---

## 01:50 常用元件

[螢幕] 打出 Text、Button、Icon，Icon 補不到 import。

[旁白]
常用元件有 Text 文字、Button 按鈕、還有 Icon 圖示。Text、Button、Color 按 Alt Enter 都補得到 import，但 Icon 的 Icons.Default.Star 會一直補不出來，顯示找不到 Icons。

[螢幕] 開 build.gradle.kts Module app，加 material-icons-extended、Sync。

[旁白]
這正好教你一個 Android 幾乎天天要做的技能：加相依套件。這個圖示放在一個預設沒安裝的套件裡，要自己加。左邊找到 Gradle Scripts、build.gradle.kts Module app，注意是 app 那個，在 dependencies 區塊裡加一行 material-icons-extended，然後上面會跳出 Sync Now，點它同步、下載套件、等一下。Sync 完，Icon 就不是紅字了，再按 Alt Enter 補 import 就能用。
記住這個流程：某個東西一直補不到 import，多半是缺套件，去 build.gradle 的 dependencies 加一行、Sync 就有了。如果你只想先跑起來、不想碰套件，Icon 這段也可以先略過，用 Text 跟 Button 就夠做計數器了。
對照 SwiftUI，Compose 用參數跟 Modifier 調外觀，SwiftUI 用點開頭的 modifier，形式不同，目的一樣。

## 03:20 版面排列

[螢幕] 打出 Column，再改成 Row。

[旁白]
Compose 用三個容器排版。Column 垂直堆疊、由上往下，對應 SwiftUI 的 VStack。Row 水平排列，對應 HStack。Box 疊在一起，對應 ZStack。
我把這個 Column 換成 Row，就從上下排列變成左右排列。名字不同，但邏輯跟 SwiftUI 完全一致。

---

## 04:50 remember + state 互動（重點）

[螢幕] 逐行打出計數器。

[旁白]
跟 SwiftUI 的 @State 對應，Compose 用 remember mutableStateOf 來管理會變動的狀態。我們做計數器。
關鍵是這行：var count by remember mutableStateOf 0。mutableStateOf 建立一個可觀察的狀態，初始值 0。remember 讓這個狀態在畫面重繪時被記住，不會每次重畫都歸零。而當 count 改變，Compose 會自動重新繪製用到它的畫面，這叫重組。

[螢幕] 模擬器跑，按按鈕數字跳。★

[旁白]
所以我按下加一，count 變 1，畫面數字自動更新，我完全不用手動改。你看，一直按一直跳。這跟 SwiftUI 資料變、畫面跟著變是完全相同的思想。你的第一個 Android 互動 App，完成了。
補一個很重要的觀念：App 顯示哪個畫面，是 MainActivity 裡 setContent 決定的，它呼叫哪個函式就顯示哪個。所以想試不同畫面，只要改 setContent 呼叫的函式名就好。而且多個 Composable 函式可以同時留在檔案裡互不影響，沒被呼叫的只是沒顯示、不用刪。要注意，如果你把某個函式用斜線斜線註解掉，但 setContent 或 Preview 還在呼叫它，就會報找不到，記得呼叫處也要一起改。

## 08:20 把 App 裝到你自己的 Android 手機

[螢幕] 手機開開發者選項、USB 偵錯、接線、Android Studio 選手機 Run。

[旁白]
在模擬器跑很方便，但裝到自己手機更有感。好消息是，Android 裝實機比 iOS 簡單很多，不用付費帳號、不用簽署、不用信任開發者那一串。
三步驟：第一，手機開發者選項，到設定、關於手機，在版本號碼上連點七下，就會變成開發者。第二，開 USB 偵錯，回設定會多出開發者選項，進去打開 USB 偵錯。第三，用線接上電腦，手機跳出允許 USB 偵錯就點允許。
接著回 Android Studio，上方裝置選單會出現你的手機名稱，選它、按 Run，App 就裝到你手機上跑起來了。如果沒出現手機，確認 USB 偵錯有開、換一條能傳輸的線、手機上有按允許。
