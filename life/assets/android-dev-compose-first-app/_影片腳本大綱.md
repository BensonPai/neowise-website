# 影片腳本大綱：用 Jetpack Compose 做第一個 App（AND-3）

> 對應文章：android-dev-compose-first-app
> 影片定位：口說 + Android Studio 螢幕錄影（刻畫面、看預覽、模擬器跑計數器）。
> 建議長度：8~10 分鐘。成就感集數。

---

## 開場（20 秒）
- 鉤子：「這集做出第一個會動的 Android App！做過 SwiftUI 的你會超有既視感。」
- 成果：計數器。

## 段落一：Composable（1.5 分，螢幕）★
- @Composable 函式描述畫面、預覽即時看。
- 對照 SwiftUI 的 View。

## 段落二：常用元件（1.5 分，螢幕）
- Text（參數調外觀）、Button（onClick）、Icon。
- 對照：Compose 用參數/Modifier、SwiftUI 用 modifier。

## 段落三：版面排列（1.5 分，螢幕）★
- Column 垂直、Row 水平、Box 疊放（對應 VStack/HStack/ZStack）。
- 現場 Column 換 Row 看變化。

## 段落四：remember + state 互動（2.5 分，螢幕）★★重點
- var count by remember { mutableStateOf(0) }。
- mutableStateOf 可觀察、remember 記住、count 變自動重組。
- 模擬器跑、按按鈕數字跳。★成就感

## 段落五：動手改（1 分，螢幕）
- 加減一、歸零、改樣式、Row 排兩顆按鈕。

## 段落六：裝到實體 Android 手機（1.5 分，螢幕）★
- 比 iOS 簡單：不用付費、不用簽署、不用信任開發者。
- 手機設定 → 關於手機 → 版本號碼連點 7 下開開發者選項。
- 開 USB 偵錯 → 接線 → 手機點「允許 USB 偵錯」。
- Android Studio 選手機名稱 → Run，裝上去跑起來。

## 收尾（30 秒）
- 約 2~3 週（做過 SwiftUI 更快）。可挑戰 BMI 計算機。
- 預告 AND-4：Room 與網路 API。
- CTA：訂閱、看文章、留言。🐾
