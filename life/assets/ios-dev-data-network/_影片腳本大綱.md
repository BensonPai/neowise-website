# 影片腳本大綱：讓 App 記住資料、連上網路（iOS-4）

> 對應文章：ios-dev-data-network
> 影片定位：口說 + Xcode 螢幕錄影（實作 @AppStorage 記暱稱、串一個公開 API 顯示資料）。
> 建議長度：9~11 分鐘（觀念較密，可稍長）。

---

## 開場（20 秒）
- 鉤子：「App 會動了，但一關就忘、又不會連網。這集讓它變成真正實用的工具。」
- 兩部分：本機記資料、網路抓資料。

## 段落一：UserDefaults（1.5 分，螢幕）★
- 用 key 存值、讀值，App 關掉再開還在。
- 提醒只適合小資料，不是資料庫。

## 段落二：@AppStorage（1.5 分，螢幕）★
- SwiftUI 專用，一行把 UserDefaults 綁到畫面。
- 做「記住暱稱」的輸入框，改了自動存、自動顯示。

## 段落三：三個名詞（1.5 分，口說 + 流程圖）
- API 是資料窗口、JSON 是資料格式、URLSession 是發請求工具。
- 流程：請求 → 回傳 JSON → 解析 → 顯示。

## 段落四：Codable（1.5 分，螢幕）
- 照 JSON 欄位定義 struct，Swift 自動轉換。

## 段落五：URLSession 實際抓（2.5 分，螢幕）★★重點
- async/await 寫法、do/catch 處理錯誤、guard let 檢查網址。
- 實際抓一個公開 API、印出資料。

## 段落六：在 SwiftUI 呼叫（1 分，螢幕）
- 抓到存進 @State、畫面自動更新。
- .task 畫面出現就載入。

## 收尾（30 秒）
- 練法：找免費公開 API 把請求→解析→顯示跑通；把舊 App 加上連網。
- 約 2~3 週。預告 iOS-5：上架 App Store。
- CTA：訂閱、看文章、留言。🐾
