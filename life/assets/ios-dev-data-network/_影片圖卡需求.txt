用途：影片中的「概念說明」圖卡（非 Xcode 實錄），建議用 Canva 製作。

======================================================================
圖卡清單（共 3 張）
======================================================================

1) card-userdefaults.png（對應 00:20 UserDefaults）
   內容：UserDefaults 概念與限制
     - 一把鑰匙存一個值、自動保存、關掉再開還在
     - 只適合少量簡單資料（不是資料庫）
     - 存本機非雲端、沒加密（密碼請用 Keychain）
   版式：16:9，鑰匙→值示意 + 三點提醒

2) card-api-flow.png（對應 03:20 三個名詞）★最重要
   內容：連網流程圖
     App 發請求 → 伺服器回傳 JSON → Codable 轉成 Swift 資料 → 顯示在畫面
   旁註：API=資料窗口、JSON=鍵配值格式、URLSession=發請求工具
   版式：16:9，橫向流程圖

3) card-fetch-steps.png（對應 06:20 URLSession，選配）
   內容：抓資料三步 + 一個原則
     1 準備網址(guard let) 2 await 發請求 3 解析成 struct
     原則：網路會出錯 → 一定要 do/catch
   小提醒：先把 API 網址貼瀏覽器看欄位，再照著寫 struct
   版式：16:9

======================================================================
要自己錄的「Xcode 實錄」畫面（主體）
======================================================================
- UserDefaults 存值/讀值
- @AppStorage 綁 TextField，改名字自動存、重開還在
- struct Weather: Codable
- fetchWeather：async/await、do/catch、guard let 逐行
- 瀏覽器打開 JSONPlaceholder 看回傳 JSON 欄位
- 照 JSON 寫 Todo struct、換真網址、模擬器跑出真資料 ★
- .task + @State 在 View 內呼叫載入
- （補充）連不到網路 Code -1003：改用 iPhone 模擬器跑
