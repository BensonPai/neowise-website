# 影片腳本大綱：Android 開發第一步（AND-1）

> 對應文章：android-dev-setup-tools
> 影片定位：口說 + 螢幕錄影（Android Studio 安裝、設定精靈、模擬器、建專案）。
> 建議長度：8~10 分鐘。

---

## 開場（20 秒）
- 鉤子：「iOS 走完換 Android，好消息是任何電腦都能開始，不用買 Mac。」
- 今天四件事：裝 Android Studio、認識 SDK 與模擬器、Google 帳號、Kotlin 與 Compose。

## 段落一：安裝 Android Studio（1.5 分，螢幕）★
- 官網下載、選作業系統、一路預設。
- 設定精靈自動下載元件，要等。硬體建議 16GB。

## 段落二：SDK 與模擬器（1.5 分，螢幕）
- SDK 是開發工具總稱、SDK Manager 管版本。
- 模擬器/AVD 在電腦上模擬手機、Device Manager 新增。

## 段落三：Google 帳號（1 分，口說）
- 學習用平常的 Google 帳號免費。
- 上架才要開發者帳號、一次性 25 美元、終身。
- 預告上架有新手規則（封閉測試），上架篇講。

## 段落四：Kotlin 與 Compose（1.5 分，口說 + 圖）
- Kotlin = 語言（對應 Swift）、Compose = 畫面（對應 SwiftUI）。
- 學過 iOS 的人超有既視感。
- 堆疊：電腦 → Android Studio → Kotlin → Compose。

## 段落五：建立第一個專案（1.5 分，螢幕）★
- 歡迎畫面 New Project → 選 Phone and large screens、範本選 Empty Activity（Compose 範本）。
- ⚠️ 別選 Basic/Empty Views Activity（那是舊的 Views/XML，不是 Compose）。
- 填設定：Name、Package name、Language 選 Kotlin、Minimum SDK 用預設、Build config 用 Kotlin DSL → Finish。
- 等 Gradle 建置（要等幾分鐘）→ 進主畫面。

## 段落六：建模擬器、跑起來（1.5 分，螢幕）★重要
- Android 跟 iOS 不同：要自己先建模擬器，不然按 Run 沒反應。
- Device Manager → Create Virtual Device → 選 Pixel → 選系統映像（可能要下載）→ Finish。
- 上方選模擬器 → Run ▶ → 模擬器開機（第一次較久）→ App 出現。

## 收尾（30 秒）
- 這步約 3~5 天（學過 iOS 更快）。目標：建專案、建模擬器、跑起來。
- 預告 AND-2：Kotlin 基礎。
- CTA：訂閱、看文章、留言。🐾
