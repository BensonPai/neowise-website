要自己錄的「螢幕實錄」畫面（主體，務必錄實際操作）
======================================================================
- 安裝 Android Studio：官網下載頁 → 安裝程式 → 第一次啟動設定精靈下載元件
- SDK 與模擬器：SDK Manager、Device Manager 畫面
- 建立專案：New Project → 選 Empty Activity（提醒別選 Views 範本）→ 填設定
             → Finish → Gradle 建置 → 主畫面
- 建模擬器跑 App：Device Manager → Create Virtual Device → 選 Pixel + 系統映像檔
                   → Run → 模擬器開機跑出 App

> 資料夾已有可當輔助／靜態畫面的截圖：
>   as-welcome / as-template / as-options / as-main
>   （操作過程仍建議錄動態畫面較清楚，截圖當補充）
