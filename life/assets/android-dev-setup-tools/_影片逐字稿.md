嗨，我是智慧喵。iOS 的學習路徑我們走完了，這一集開始換 Android。

## 00:20 安裝 Android Studio

[螢幕] Android 官網下載頁、安裝程式。

[旁白]
Android Studio 是 Google 官方的開發工具，完全免費，是你寫 App 的主場。
到 Android 開發者官網下載，選對應你作業系統的版本，執行安裝程式，一路照預設點下去就好。

[螢幕] 第一次啟動、設定精靈下載元件。

[旁白]
第一次啟動時，它會透過一個設定精靈幫你下載必要的元件，包含 SDK、模擬器這些。這步要一點時間跟網路流量，接好電源耐心等。硬體上建議記憶體 16GB 以上會比較順。

---

## 01:50 SDK 與模擬器

[螢幕] SDK Manager、Device Manager 畫面。

[旁白]
剛剛裝的那些元件，先認識兩個。
第一個是 Android SDK，它是開發 Android 需要的工具跟函式庫的總稱，Android Studio 會幫你管理，透過 SDK Manager 就能下載更新不同 Android 版本。
第二個是模擬器，它在電腦上模擬出一支 Android 手機，讓你不用真機也能測試。第一次用設定精靈裝好的預設模擬器就行，之後想測不同機型或版本，用 Device Manager 新增。

---

## 03:20 Google 帳號

[螢幕] 口播或帳號畫面。

[旁白]
寫程式、用模擬器測試，用你平常的 Google 帳號就行，不用花錢。
只有要把 App 上架到 Google Play 時，才需要註冊開發者帳號，這是一次性的 25 美元，付一次終身有效，不像 iOS 要年繳。
建議現在別急著付費，等後面上架篇真的要發布再說。要先提醒你，Google Play 上架有一些新手不知道的規則，比如新的個人帳號要先做封閉測試，這些我在上架那篇會完整講。

---

## 04:20 Kotlin 與 Jetpack Compose

[螢幕] 工具鏈堆疊圖。

[旁白]
環境好了，認識兩個核心工具。
Kotlin 是程式語言，是你用來寫邏輯的工具，是 Google 現在主推的官方語言，現代、簡潔、安全。你可能聽過 Java 也能寫 Android，那比較舊，新手直接學 Kotlin 就好。
Jetpack Compose 是畫面框架，用宣告式的寫法刻介面。
如果你學過 iOS，這裡會有超強既視感：Kotlin 對應 Swift，Compose 對應 SwiftUI，設計理念幾乎一樣。這就是為什麼學過一個平台再學另一個會快很多。堆疊關係是電腦、Android Studio、Kotlin、Compose。

---

## 05:50 建立第一個專案

[螢幕] 歡迎畫面 New Project → 選 Empty Activity → 填設定 → Finish → 主畫面。

[旁白]
環境好了，我們建一個專案看看。歡迎畫面點 New Project。左邊選 Phone and large screens，範本這裡很重要，選 Empty Activity，就是上排中間那個藍綠色方塊，它是 Jetpack Compose 的空白範本，也是我們這系列要用的。
特別提醒，清單裡還有 Basic Views Activity 跟 Empty Views Activity，那些是舊的 Views、也就是 XML 寫法，不是 Compose，別選錯，不然後面 Compose 篇會對不上。
選好 Empty Activity 按 Next，填設定：Name 打你的 App 名稱，Package name 用預設就好，Language 選 Kotlin，Minimum SDK 用預設，Build configuration 用 Kotlin DSL，然後按 Finish。
按下去後 Android Studio 會開始建立專案、下載相依套件，第一次會跑一個叫 Gradle 的建置工具，要等幾分鐘。跑完進到主畫面，就代表專案建好了。

---

## 07:20 建模擬器、把 App 跑起來

[螢幕] Device Manager 建立模擬器 → 選裝置 → Run → 模擬器開機跑出 App。

[旁白]
專案建好，你可能想按上面綠色的 Run 跑跑看，但很可能沒反應。這是 Android 跟 iOS 很不一樣的地方：iOS 裝好就有模擬器可選，Android 要自己先建一台，沒有可跑的裝置，Run 就沒地方執行。
建模擬器很簡單：點 Run 旁邊裝置下拉選單裡的 Device Manager，或選單 Tools、Device Manager，按加號 Create Virtual Device，選一支手機比如 Pixel，選一個系統映像檔，如果要下載就先下載，然後 Finish。
建好後，上方下拉選單選這台模擬器，按 Run。模擬器會開機，第一次比較久，一兩分鐘正常，然後你的 App 就出現在模擬的手機上了。看到就代表 Android 環境完全打通。
