# 影片腳本大綱：用 SwiftUI 做第一個 App（iOS-3）

> 對應文章：ios-dev-swiftui-first-app
> 影片定位：口說 + Xcode 螢幕錄影（實際刻畫面、看即時預覽、模擬器跑計數器）。
> 建議長度：10~12 分鐘。這集最有成就感，觀眾看到 App 真的動起來、還裝進自己手機。

---

## 開場（20 秒）
- 鉤子：「前兩集裝環境、學語言，這集我們真的做出第一個會動的 App！」
- 預告成果：做一個計數器，按按鈕數字就加一。
- 程式碼在說明欄文章。

## 段落零：先建 App 專案（40 秒，螢幕）
- 跟上一集建 Playground 一樣的入口，這次選 App。
- New Project 旁箭頭 → 選 App → 直接建好（不問名稱、一步到位）。
- 建好點 ContentView，右邊有 Hello world 預覽。
- 一句帶過：專案會叫 Untitled Project，學習用沒差；想取名最快是按 File → Save，會跳出視窗填名稱＋位置（因為還沒存過）。

## 段落一：View 是什麼（1.5 分，螢幕）★
- 看 Xcode 自動給的 ContentView。
- 拆解 struct / body / Text。
- 展示右邊即時預覽：改文字、預覽跟著變。

## 段落二：常用元件（1.5 分，螢幕）
- Text（加 modifier：font、顏色）。
- Button（按下要做的事）。
- Image + SF Symbols。
- 解釋 modifier 是「幫元件加裝飾」，可串接。

## 段落三：版面排列 Stack（1.5 分，螢幕）★
- VStack 垂直、HStack 水平、ZStack 疊放。
- 現場把 VStack 換成 HStack 看排列改變。

## 段落四：@State 做互動（2.5 分，螢幕）★★重點
- 打出計數器：@State count、Text 顯示、Button 加一。
- 講關鍵：@State 變 → SwiftUI 自動重畫。
- 模擬器跑起來，按按鈕看數字跳。★成就感時刻

## 段落五：動手改（1 分，螢幕）
- 加減一、歸零按鈕；改顏色字體；HStack 排兩顆按鈕。
- 鼓勵觀眾自己試、改壞不怕。

## 段落六：裝到實體 iPhone（2 分，螢幕）★很受歡迎
- 免費 Apple ID 就能裝，不用先付費。
- 流程：Xcode 登入 Apple ID → Signing & Capabilities 選個人團隊 → 接線信任電腦 → 手機開開發者模式 → 選裝置執行 → 設定裡信任開發者。
- 手拿 iPhone 展示自己做的 App 跑起來（成就感畫面）。
- 提醒免費帳號限制：憑證 7 天、最多 3 個 App。

## 收尾（30 秒）
- 這步約 2~3 週，可挑戰 BMI 計算機當綜合練習。
- 預告 iOS-4：資料儲存與網路 API，讓 App 變實用。
- CTA：訂閱、看文章、留言。🐾
