## 00:20 先建一個 App 專案

[螢幕] 歡迎畫面 New Project → 選 App → 選項 → Create，開好點 ContentView。

[旁白]
這一集要做的是真正的 App，不是上一集的 Playground，所以先建一個 App 專案。入口跟上一集建 Playground 一樣，只是這次選 App。歡迎畫面點 New Project 旁的箭頭、選 App，就這樣，Xcode 會直接幫你建好一個能跑的空白 App，馬上進主畫面。點左邊的 ContentView，就會看到預設程式碼跟右邊的即時預覽，顯示 Hello world。
你會發現專案叫 Untitled Project，這正常，因為這個捷徑不問你名稱、直接用預設建好，它其實還沒真正存到硬碟，學習用完全沒差。如果你想給它取名字，最簡單的方法是按 File、Save，因為專案還沒存過，Xcode 會跳出視窗要你填名稱跟位置，你打的名字就變成專案名了，很方便。

## 01:00 View 是什麼

[螢幕] 顯示自動產生的 ContentView。

[旁白]
在 SwiftUI 裡，畫面上的每一個東西，一段文字、一個按鈕、整個頁面，都是一個 View，視圖。你用描述的方式告訴它畫面長怎樣，它幫你畫出來。
剛剛建好的 ContentView 就是一個視圖，這個 body 裡面放的就是畫面內容，現在放的是一個顯示 Hello world 的文字。

[螢幕] 改 Text 內容，右邊 Preview 即時變化。

[旁白]
你看右邊這個預覽，我改一下文字，預覽馬上就跟著變，不用重跑，超級方便。

## 01:50 常用元件

[螢幕] 打出 Text 加 modifier、Button、Image。

[旁白]
SwiftUI 內建很多現成元件。最常用的像是 Text 文字，我可以在後面加上這些點開頭的東西，改字體大小、改顏色。這種點開頭的寫法叫修飾符，就像幫元件加裝飾，可以一個接一個串起來。
再來是 Button 按鈕，按下去要做的事就寫在這個大括號裡。還有 Image，搭配 Apple 內建的 SF Symbols，有幾千個現成圖示可以用。

## 03:20 版面排列

[螢幕] 打出 VStack，展示由上而下排列。

[旁白]
單一元件會了，怎麼把多個排在一起？SwiftUI 用三個容器。
VStack 是垂直堆疊，由上往下排。HStack 是水平排列，由左往右。ZStack 是疊在一起、前後重疊。
我這裡用 VStack 把標題、副標題、按鈕由上到下排好。

[螢幕] 把 VStack 改成 HStack，預覽變成水平排列。

[旁白]
如果我把 VStack 改成 HStack，你看，它們馬上變成左右排列。用這三個容器互相組合，就能排出各種版面。

## 04:50 @State 做出互動計數器（重點）

[螢幕] 逐行打出計數器程式碼。

[旁白]
到這裡畫面都還是死的。真正的 App 要能反應操作，這就要用到 SwiftUI 很關鍵的觀念：狀態。我們來做計數器。
我先宣告一個變數 count，前面加上 @State 這個標記，它告訴 SwiftUI，這個數字會變動。畫面上用一個 Text 顯示目前的數字，再放一個加一按鈕，按下去就讓 count 加一。

[螢幕] 模擬器執行，按按鈕數字跳動。★

[旁白]
關鍵來了：當這個 @State 變數的值改變，SwiftUI 會自動重新畫畫面。所以我按下加一，count 從 0 變 1，畫面上的數字就自動更新了——我完全不用手動去改畫面上的文字，它自己跟上。
你看，按一下加一、再按一下，數字一直跳。這，就是你的第一個互動 App。這種資料一變、畫面自動跟著變的機制，是 SwiftUI 最核心也最強大的地方。

## 08:20 把 App 裝到你自己的 iPhone

[螢幕] Xcode 登入 Apple ID、Signing 設定、接上 iPhone。

[旁白]
在模擬器上跑很方便，但把 App 裝到自己手上那支真 iPhone、用手指點，那個「這是我做的」的感覺完全不一樣。好消息是，用免費的 Apple ID 就能裝到自己的手機，不用先付費。
步驟是這樣：先登入 Apple ID。注意設定的位置，是螢幕最左上角那個 Xcode 選單，不是 File，點進去選 Settings，快捷鍵是 Command 加逗號，舊版叫 Preferences。進去切到 Apple Accounts 分頁，舊版叫 Accounts，登入你的 Apple ID，它會自動幫你建一個個人團隊。接著點專案的 Signing & Capabilities 分頁，勾選自動管理簽署，Team 選你剛登入的帳號；如果 Bundle Identifier 出現紅字衝突，改成一個獨一無二的字串就好。

[螢幕] 接線、手機信任電腦、開開發者模式。

[旁白]
用線把 iPhone 接上電腦，第一次接手機會問要不要信任這台電腦，點信任、輸入密碼。較新的 iOS 還要手動開開發者模式，到手機的設定、隱私權與安全性、開發者模式，打開它、重新啟動。

[螢幕] Xcode 選裝置執行，手機設定裡信任開發者，App 跑起來。★

[旁白]
回到 Xcode，把執行目標從模擬器改成你的 iPhone，按執行。
這裡你很可能遇到一個錯誤，說你的手機 iOS 版本不符合 App 的 deployment target，比如手機是 18、App 卻要求 27。不用升級手機，把 App 的最低支援版本調低就好：點左邊藍色專案圖示、選 TARGETS 底下的專案、General 分頁，找到 Minimum Deployments，把它改成一個比你手機低的版本，比如 17，再按執行就行了。
過程中可能會跳出一個視窗，說 codesign 想存取鑰匙圈、要你輸入密碼。這裡要輸入的是你這台 Mac 的登入密碼，就是開機解鎖 Mac 那組，不是 Apple ID 密碼。輸入後按永遠允許，之後就不會一直跳。這是 Xcode 幫 App 簽署的正常步驟。
第一次裝，App 會裝上去但點不開，出現不受信任的開發者，這時到手機設定、一般、VPN 與裝置管理，找到你的 Apple ID 點信任，再回桌面點開——你做的計數器，就跑在你自己的 iPhone 上了。
要提醒兩個免費帳號的限制：憑證只有七天，七天後 App 會失效，重新從 Xcode 裝一次就好；而且同時最多裝三個 App。這對學習跟自己測試完全夠用，等你要長期留在手機或給別人裝，就是後面上架篇付費帳號的範圍了。
