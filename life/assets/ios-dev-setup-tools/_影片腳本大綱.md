# 影片腳本大綱：iOS 開發第一步（環境準備）

> 對應文章：ios-dev-setup-tools（【App 開發指南】iOS 開發第一步）
> 影片定位：口說 + 螢幕錄影示範。文章負責可搜尋、可複製的細節；影片負責「看操作」。
> 建議長度：8~10 分鐘。

---

## 開場（15~20 秒）

- 鉤子：「想做 iPhone App，但第一關就卡住——到底要準備什麼？這支影片帶你從零把開發環境裝好。」
- 一句話講清楚今天會做完的事：為什麼要 Mac、裝 Xcode、認識 Xcode 介面、Apple ID、認識 Swift/SwiftUI。
- 提醒：完整文字步驟與注意事項放在部落格文章（說明欄連結）。

## 段落一：為什麼要 Mac（40 秒，口說為主）

- 直說硬條件：Xcode 只能裝 macOS，Windows/Linux 不行。
- 哪種 Mac 夠用：MacBook Air / Mac mini（M 系列），記憶體建議 16GB，二手也行。
- 一句帶過：只有 Windows 又想先省錢的人，可以先做 Android（帶到總覽篇）。

## 段落二：安裝 Xcode（1.5~2 分鐘，螢幕錄影重點）★這段影片最有價值

- 螢幕錄影：打開 Mac App Store → 搜尋 Xcode → 點下載。
- 口說提醒：檔案很大、要等、接電源。
- 螢幕錄影：裝好後第一次打開 Xcode → 附加元件安裝 → 出現歡迎畫面（能新建專案）。
- 提醒 macOS 版本要夠新（帶一句「詳細版本需求看文章／Apple 官方頁」）。

## 段落三：認識 Xcode 介面（1.5~2 分鐘，螢幕錄影）★對新手很有用

- 新建專案：歡迎畫面點 New Project 旁箭頭 → 選 App → 進 Choose options 畫面。
- 重點：新版 Xcode 已不問 SwiftUI/Storyboard、不問語言（App 專案預設就是 SwiftUI + Swift）。
- 選項畫面欄位：Product Name（App 名）、Team（先留）、Organization Identifier（com.你的名字）、Bundle ID（自動）、Testing System 選 None、Storage 選 None（SwiftData/Core Data 之後要存資料再用）。
- 按 Next → 選存放位置（例如桌面）、可勾 Create Git repository → 按 Create 才建好。
- 補充：走 Choose Template 會多一個範本頁（選 App → Next 進同一個選項畫面）。
- 帶觀眾看主要區塊：① 導覽器（左，找檔案）② 編輯區（中，寫程式，預設開 MyApp）③ 偵錯區（底，看 log/錯誤）④ 檢閱器（右，調屬性）。
- Canvas 即時預覽：要點含畫面的檔案（ContentView）才出現，可能要手動開；MyApp 沒畫面看不到很正常，下集做畫面用到。
- 頂部工具列：裝置可能是 My Mac，示範切成 iPhone 模擬器；▶ 執行鈕。
- 一句總結：現在只要記「左邊找檔案、中間寫程式、上面按執行」就夠。

## 段落四：Apple ID 與開發者帳號（1 分鐘，口說為主）

- 免費 Apple ID 就能寫、能在模擬器跑。
- 要上架 / TestFlight 才需付費 Apple Developer Program（每年 US$99，標「以官方為準」）。
- 建議：學習階段先別付費，要上架再說。
- 提醒開雙重認證。

## 段落五：Swift vs SwiftUI（1 分鐘，口說 + 簡單畫面）

- 用比喻講：Swift = 建材工法（語言、邏輯）；SwiftUI = 室內設計工具（畫面）。
- 堆疊關係：Mac → Xcode → Swift → SwiftUI。
- 一句帶過 UIKit：新手直接學 SwiftUI 就好。

## 收尾（30 秒）

- 螢幕錄影小彩蛋（可選）：新建一個空專案 → 按下執行 → 模擬器跑出空白 App。給觀眾「原來這麼快就能跑起來」的成就感。
- 這步目標：能開 Xcode、建空專案、模擬器跑起來。
- 預告下一支：Swift 語言基礎。
