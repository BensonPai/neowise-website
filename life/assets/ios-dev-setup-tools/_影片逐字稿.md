## 00:20 為什麼一定要 Mac

[螢幕] 一台 Mac 的畫面，或簡單的圖示。

[旁白]
先講一個最現實、也最多人踩雷的重點：開發 iPhone App，你需要一台 Mac。
為什麼？因為 iOS 開發唯一的官方工具 Xcode，只能安裝在 macOS 上，Windows 跟 Linux 都不行。這不是建議，是硬性規定。
那要買多好的 Mac 呢？好消息是，學習跟開發中小型的 App，其實不用頂規。
近幾年的 MacBook Air、或是最划算的 Mac mini，都很夠用。記憶體建議 16GB 會比較舒服，因為 Xcode 蠻吃記憶體的。硬碟也記得留個 50GB 以上的空間。
如果預算有限，買一台二手的 Mac 也是很務實的選擇。
那如果你手上只有 Windows 電腦，又還不想花錢買 Mac，其實可以先從 Android 開發入門，這部分我在系列的總覽篇有講，有興趣可以先去看。

## 01:00 安裝 Xcode（實際操作）★重點

[螢幕] 打開 Mac App Store。

[旁白]
Mac 準備好之後，我們就來裝 Xcode。它是 Apple 官方的開發工具，最棒的是——完全免費。寫程式、設計畫面、測試、上架，全部都在它裡面完成。
安裝很簡單，跟著我做。

[螢幕] 在 App Store 搜尋列輸入 Xcode。

[旁白]
打開 Mac 內建的 App Store，在搜尋欄打上 Xcode。

[螢幕] 點下載/安裝按鈕，顯示下載進度。

[旁白]
找到之後，點下載安裝就可以了。這裡要提醒你：Xcode 的檔案非常大，十幾 GB 起跳，所以下載加安裝會花不少時間。建議接上電源、用穩定的網路，然後去泡杯咖啡等它跑完。
另外，Xcode 對 macOS 的版本有要求，如果 App Store 顯示你的系統太舊、裝不了最新版，先把 macOS 更新到最新就可以了。詳細的版本需求我放在文章裡。

[螢幕] Xcode 第一次啟動、安裝附加元件、出現歡迎畫面。

[旁白]
裝好之後第一次打開 Xcode，它會再安裝一些附加元件，跟著點同意、安裝就好。
當你看到這個歡迎畫面，可以新建專案的時候，就代表你成功了。

## 03:00 認識 Xcode 介面

[螢幕] 新建專案：Create New Project → iOS → App，展示選項。

[旁白]
第一次打開 Xcode 會有點嚇到，畫面塞得很滿。別緊張，你不用一開始就全懂，先認得幾個主要區塊就好。
我們新建一個專案來看，在歡迎畫面點 New Project 旁邊的小箭頭，會展開一個選單，直接選 App。
接著會進到選項設定畫面。新版 Xcode 這頁很單純，已經不會問你要 SwiftUI 還是 Storyboard、也不問語言了，因為現在建 App 專案預設就是 SwiftUI 加 Swift，這正好是我們要的。你只要填幾個東西：Product Name 打你的 App 名稱；Team 先留著，之後要裝到實體 iPhone 再設；Organization Identifier 用反向網域，像 com 點你的名字，它會自動組成下面的 Bundle Identifier，那是 App 的唯一 ID，不用手動改；Testing System 跟 Storage 新手都選 None 就好，Storage 裡的 SwiftData、Core Data 是資料庫方案，之後要存大量資料再用。填好按 Next，會再跳一個視窗要你選存放位置，比如選桌面，可以勾 Create Git repository 幫專案做版本控制，建議勾，最後按右下角的 Create，專案才真正建好。
補充一下，如果你是走選單最下面的 Choose Template，會多一個範本選擇畫面，上面有 Multiplatform、iOS 這些分頁，點 App、按 Next，就會進到剛剛講的同一個選項設定畫面。兩條路殊途同歸。

[螢幕] 進入主畫面，依序指出五大區。

[旁白]
建好進到主畫面，先認幾個主要區塊。
左邊是導覽器，你專案裡所有檔案都在這，像 ContentView、MyApp 這些，要開哪個就點它。中間是編輯區，這是寫程式的主場，剛建好預設打開的是 MyApp 這個 App 進入點檔案。底部是偵錯區，App 跑起來後 print 的訊息、錯誤、當機資訊都在這。最右邊是檢閱器，顯示選取項目的屬性，剛開始用得少。
另外講一下 SwiftUI 的即時預覽，也叫 Canvas。它要點開有畫面內容的檔案，像 ContentView，才會出現。你試著點一下左邊的 ContentView，右側就會跳出一個小手機預覽，顯示一個地球圖示跟 Hello world，那就是範本預設的畫面。剛建好預設開的是 MyApp，它沒有畫面，所以那時看不到預覽是正常的。如果預覽沒自動出現，可以從編輯區右上角的按鈕打開，下一集做畫面時會大量用到。
最後是頂部工具列，中間會顯示要跑在哪個裝置，剛建好可能是 My Mac，你可以點它換成 iPhone 模擬器。旁邊那個播放鍵就是執行鈕。
介面看起來很多，但現階段你只要記三件事就夠開始：左邊找檔案、中間寫程式、上面按執行。

## 05:00 Apple ID 與開發者帳號

[螢幕] Apple ID 設定畫面，或簡單圖示。

[旁白]
接下來講帳號。好消息是，在學習階段，寫程式跟在模擬器上測試，用你平常在用的那個免費 Apple ID 就夠了，不用花任何錢。
那什麼時候需要付費呢？當你想把 App 正式上架到 App Store，或是想用 TestFlight 邀請朋友幫你測試的時候，就必須加入付費的 Apple Developer Program。
它的費用是每年 99 美元，而且要持續續約才能維持上架。實際金額以 Apple 官方為準。
所以我的建議是：現在別急著付費，先用免費帳號開始學、開始寫。等到你真的要上架的時候再來付，把錢花在刀口上。
最後別忘了，幫你的 Apple ID 開啟雙重認證，這是 Apple 的基本要求，也保護你的帳號安全。

## 06:00 Swift 與 SwiftUI 是什麼

[螢幕] Swift 與 SwiftUI 的堆疊關係圖。

[旁白]
環境都裝好了，最後認識一下接下來會用到的兩個核心工具，這兩個很多人會搞混。
第一個是 Swift，它是程式語言，是你用來寫邏輯的工具，會告訴 App 該怎麼運作。
第二個是 SwiftUI，它是畫面框架，用來刻你看得到的介面，像是按鈕、文字、清單這些東西。
我用一個比喻你就懂了：如果 App 是一棟房子，Swift 就是建材和工法，SwiftUI 就是室內設計的工具。兩個搭配起來，畫面跟功能就都做得出來了。
它們的關係是這樣堆疊的：最底層是 Mac 硬體，往上是 Xcode 開發工具，再上面是 Swift 語言，最上面是 SwiftUI 畫面框架。今天我們把最底下兩層準備好了，接下來就是往上學語言跟畫面。

## 07:30 建個空專案跑跑看

[螢幕] Xcode 新建一個空專案 → 按下執行 → 模擬器跑出空白 App。

[旁白]
在結束之前，我們來做一件有成就感的事。
打開 Xcode，新建一個專案，什麼都先不用改，直接按下這個執行按鈕。
你看，模擬器打開了，我們的第一個 App，雖然是空白的，但它真的在這台模擬的 iPhone 上跑起來了。
是不是比想像中簡單很多？這一步的目標就是這樣——能打開 Xcode、建一個空專案、在模擬器把它跑起來。做到這裡，你就正式踏出 iOS 開發的第一步了。
