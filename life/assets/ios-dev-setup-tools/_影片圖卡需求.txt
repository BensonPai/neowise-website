圖卡清單（共 3 張，對應逐字稿各段）

1) card-mac-spec.png（對應 00:20 為什麼要 Mac）
   用途：講 Mac 需求時出現
   內容：Mac 選購建議重點

     - 記憶體：建議 16GB
     - 硬碟：留 50GB 以上
     - 預算有限：二手也可
   版式：16:9，條列 + 一台 Mac 的簡單圖示

     左「學習階段」：免費 Apple ID／可寫程式、可在模擬器測試
     右「要上架 / TestFlight」：付費 Apple Developer Program／每年 US$99（以官方為準）
   版式：16:9，左右分欄，右欄標「要上架才需要」；底部一句「記得開雙重認證」

3) card-swift-stack.png（對應 06:00 Swift 與 SwiftUI）

======================================================================
要自己錄的「螢幕實錄」畫面（主體，務必錄實際操作）
======================================================================
- 安裝 Xcode：App Store 搜尋 Xcode → 下載 → 第一次啟動 → 附加元件 → 歡迎畫面
- 認識介面：New Project → App → 選項畫面逐欄 → Create → 主畫面五大區
             → 點 ContentView 看 Canvas 預覽 → 切 iPhone 模擬器
- 跑空專案：新建專案 → 按 Run → 模擬器跑出空白 App

> 資料夾已有可當輔助／靜態畫面的截圖：
>   xcode-welcome / xcode-template / xcode-choose-template / xcode-options /
>   xcode-save / xcode-ui / xcode-preview / code-install
>   （操作過程仍建議錄動態畫面較清楚，截圖當補充）
