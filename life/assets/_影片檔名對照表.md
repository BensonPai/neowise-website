# 影片檔名 × YouTube 標題對照表

> 用途：剪輯匯出時照「建議檔名」填 DaVinci 的 Filename；上傳 YouTube 時照「YouTube 標題」填標題。
> 檔名命名規則：`<平台-集數>_<slug>_v1.mp4`
>   - 全英文小寫 + 連字號、底線，不含中文與空格（避免上傳亂碼）。
>   - 集數前綴讓檔案在資料夾裡自然照播放順序排列。
>   - `_v1` 是版本號，重新剪輯重匯出就改 `_v2`、`_v3`，不會蓋掉舊檔。
>
> 檔名 vs 標題的差別（兩者目的不同，別混用）：
>   - 檔名 = 給自己管理，英文、好排序、不會亂碼。
>   - YouTube 標題 = 給觀眾看，中文、吸睛、含關鍵字與集數，影響點閱與搜尋。
>   - 標題為建議稿，可依實際成品微調；盡量把「痛點／成果 + 平台關鍵字」放前面。
>   - 各支的說明欄範本見各自資料夾的 _影片腳本大綱.md。

## 用法

1. **匯出**：DaVinci → Deliver 頁 → Filename 欄貼上對應「建議檔名」（不用打 `.mp4`，DaVinci 會自動加）。
2. Location 建議統一存一個資料夾（例如 `影片成品/`），這樣檔名前綴會讓它們自動排好序。
3. 重剪重匯 → 把 `_v1` 改成 `_v2`，舊版留著備份。
4. **上傳**：YouTube 上傳時標題貼對應「YouTube 標題」（可依成品微調）；說明欄照該支 _影片腳本大綱.md 的範本填。
5. **互導**：上傳後把影片 ID 填回對應文章 front-matter 的 `youtube:`，重跑 build-life.bat，文章就會自動嵌入播放器。

> SEO 小提醒：標題關鍵字盡量靠前（iOS 開發 / Android 開發 / SwiftUI / Kotlin 等）；集數用【】前綴讓觀眾一眼認出同系列、追看下一集。
