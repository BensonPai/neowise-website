## 00:20 變數與常數

[螢幕] 打出 var score、val name。

[旁白]
Kotlin 用兩個關鍵字存資料。var 是變數，值可以改。val 是常數，設定後不能改。
學過 Swift 的話，var 一樣，Kotlin 的 val 就是 Swift 的 let。習慣也一樣，能用 val 就用 val，更安全。

## 01:50 資料型別

[螢幕] 打出 Int/Double/Boolean/String 與型別推斷。

[旁白]
常見型別有 Int 整數、Double 小數、Boolean 真假值、String 文字。Kotlin 一樣有型別推斷，不寫型別它也懂。跟 Swift 幾乎一樣，只是布林型別叫 Boolean，不是 Bool。

## 03:20 流程控制

[螢幕] 打出 if、when、for、while。

[旁白]
條件判斷用 if。注意，Kotlin 的 if 條件要加括號，這跟 Swift 不一樣。
多重條件用 when，它就是 Kotlin 版的 switch，寫法更簡潔，用箭頭。
迴圈的話，for 跑範圍這樣寫，這個 1 點點 5 是範圍。while 條件成立就一直做。對了，把變數塞進文字，Kotlin 用錢字號，Swift 是反斜線括號，這叫字串模板。

## 05:20 函式

[螢幕] 打出 greet 函式。

[旁白]
函式用 fun 宣告，這是名稱，括號裡是參數，冒號後面是回傳型別。對照 Swift 的話，Swift 用 func、用箭頭 String，Kotlin 用 fun、用冒號 String。概念完全一樣，只是關鍵字跟符號略不同。

## 06:50 null 安全（重點）

[螢幕] 打出 String? 與 ?. ?: if 判斷。

[旁白]
最後這個是 Kotlin 最重要的特色，對應 Swift 的可選型別，一樣是新手最該花時間的地方。
問題一樣：一個變數可能有值、也可能沒有值，也就是 null。Kotlin 預設不允許 null，你必須明確標示這個可以是 null，在型別後面加問號。沒加問號的變數，你想塞 null 給它，它直接報錯。
那怎麼安全使用可能為 null 的值？三個工具。第一，安全呼叫問號點，如果前面是 null，整個結果就是 null，不會爆。第二，Elvis 運算子問號冒號，對應 Swift 的雙問號，是 null 就給預設值。第三，用 if 確認不是 null 後，Kotlin 會智慧轉型，自動當它非 null 直接用。
為什麼重要？因為以為有值、結果是 null，是 App 當機最經典的原因，就是 Java 時代惡名昭彰的空指標例外。Kotlin 從語言層面逼你處理掉。
