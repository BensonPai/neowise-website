# 影片腳本大綱：Kotlin 語言基礎（AND-2）

> 對應文章：android-dev-kotlin-basics
> 影片定位：口說 + Android Studio / Kotlin Playground 螢幕錄影。
> 建議長度：8~10 分鐘。學過 Swift 者可強調對照。

---

## 開場（20 秒）
- 鉤子：「開始寫 Kotlin。學過 Swift 的你會超有感，觀念幾乎能直接搬。」
- 建議跟著打。

## 段落一：變數與常數（1.5 分，螢幕）★
- var 可改、val 不可改（val = Swift 的 let）。
- 能用 val 就用 val。

## 段落二：資料型別（1.5 分，螢幕）
- Int/Double/Boolean/String、型別推斷。
- 對照：布林叫 Boolean 不是 Bool。

## 段落三：流程控制（2 分，螢幕）★
- if 要加括號（跟 Swift 差異）。
- when（= switch，用 ->）。
- for (i in 1..5)、while；字串模板用 $。

## 段落四：函式（1.5 分，螢幕）
- fun / 參數 / : String 回傳型別。
- 對照 Swift func / -> String。

## 段落五：null 安全（2.5 分，重點）★★
- Kotlin 預設不允許 null，要加 ? 才能是 null。
- ?. 安全呼叫、?: Elvis（= Swift ??）、if 判斷智慧轉型。
- 為什麼重要：避免 NullPointerException 當機。

## 收尾（30 秒）
- 學過 Swift 約一週、否則 2~3 週。多練 null 安全。
- 預告 AND-3：Jetpack Compose 第一個 App。
- CTA：訂閱、看文章、留言。🐾
