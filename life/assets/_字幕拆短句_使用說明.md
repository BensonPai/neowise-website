# 字幕拆短句工具 使用說明

> 解決什麼問題：DaVinci 匯出的 SRT，若某條字幕是一整段長句，上傳 YouTube 會塞滿畫面、被切掉。
> 這支工具把長條目自動拆成短句（依標點斷句、時間按字數比例分配），上傳就正常。
> 特性：只拆短句，不合併、不改動原本的時間（時間沿用你 DaVinci 匯出的，最準）。

---

## 標準流程（每支影片都這樣）

1. **DaVinci 匯出 SRT**
   - Edit 頁確認時間軸最上面有字幕軌、上面有字幕。
   - Deliver 頁 → 格式選 **Custom Export**（選 YouTube 預設看不到字幕選項）。
   - 往下找 **Subtitle Settings** → 勾 **Export Subtitle** → 格式 **SRT** → **As a separate file**。
   - Render，得到一個完整 SRT。

2. **把 SRT 放進該影片的資料夾**
   - 例如放到 `faceless-tutorial-video-production/` 裡。

3. **跑拆短句工具**（在 `life/assets` 資料夾開終端機）
   ```
   node _字幕拆短句.mjs faceless-tutorial-video-production/你的檔名.srt
   ```
   - 會在同資料夾產生 `你的檔名.short.srt`（短句版）。

4. **上傳 YouTube**
   - 用那個 `.short.srt` 當字幕，語言選中文（繁體）。

---

## 調整字幕長短

- 腳本開頭的 `MAX_LEN = 20` 是每條字幕最多字數。
- 覺得字幕太碎 → 改大（例如 24）。
- 覺得還是太長 → 改小（例如 16）。

---

## 和 iOS-1 那次的差別

- iOS-1 當時用的是 **TTSMaker 的「分段」SRT**，需要「合併 + 平移時間 + 拆短」，還要手動報每段起始時間，很麻煩。
- 現在走 **DaVinci 匯出的「單一完整」SRT**，時間已經正確，只需要「拆短句」這一步，省事很多。
- 所以：**以後字幕都從 DaVinci 匯出，再跑這支工具就好**，不要再回去用 TTSMaker 的分段 SRT 合併。
