# 影片腳本大綱：讓 Android App 記住資料、連上網路（AND-4）

> 對應文章：android-dev-data-network
> 影片定位：口說 + Android Studio 螢幕錄影（DataStore 記暱稱、Retrofit 串公開 API）。
> 建議長度：9~11 分鐘。

---

## 開場（20 秒）
- 鉤子：「App 會動了，但一關就忘、又不連網。這集讓它變實用工具。」
- 兩部分：本機記資料、網路抓資料。做過 iOS 觀念共通。

## 段落一：DataStore（1.5 分，螢幕）★
- 存小設定，用 key 存值、自動保存。取代舊 SharedPreferences。
- 對應 iOS UserDefaults。

## 段落二：Room（1.5 分，螢幕）
- 大量結構化資料用 Room（底層 SQLite）。
- Entity / DAO / Database 三塊，先建立概念。

## 段落三：名詞（1.5 分，口說 + 流程圖）
- API、JSON、Retrofit、協程 suspend（對應 async/await）。

## 段落四：定義資料與 API 介面（1.5 分，螢幕）
- data class 照 JSON 定義（像 Codable）。
- interface + @GET + suspend。

## 段落五：實際呼叫（2.5 分，螢幕）★★重點
- 協程裡呼叫、try/catch 處理錯誤。
- 抓公開 API 印出資料。

## 段落六：在 Compose 顯示（1 分，螢幕）
- 資料進 state 自動更新、LaunchedEffect 畫面出現就載入（對應 .task）。

## 收尾（30 秒）
- 練法：DataStore 記暱稱、Room 存清單、Retrofit 抓公開 API。約 2~3 週。
- 預告 AND-5：上架 Google Play（含封閉測試關鍵規則）。
- CTA。🐾
