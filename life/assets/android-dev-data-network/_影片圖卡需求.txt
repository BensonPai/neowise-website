======================================================================
圖卡清單（共 3 張）
======================================================================

1) card-datastore-vs-room.png（對應 00:20~01:50）★最重要
   內容：資料儲存怎麼選
     DataStore：少量簡單設定(暱稱/開關)，=iOS UserDefaults，取代舊 SharedPreferences
     Room：大量有結構資料(清單/筆記)，官方資料庫、底層 SQLite
       三塊：Entity(一筆資料) / DAO(存取方法) / Database(本體)
   版式：16:9 左右對照

2) card-api-flow.png（對應 03:20 名詞）★最重要
   內容：連網流程圖
     App 發請求 → 回傳 JSON → 轉成 Kotlin 資料 → 顯示畫面
   旁註：API=資料窗口、JSON=格式、Retrofit=請求函式庫、協程 suspend(=iOS async/await)
   版式：16:9 橫向流程

3) card-retrofit-steps.png（對應 04:50~06:20，選配）
   內容：data class(=iOS Codable) + interface @GET + suspend
     原則：網路會出錯 → 一定要 try/catch
   版式：16:9

======================================================================
要自己錄的「Android Studio 實錄」畫面（主體）
======================================================================
- DataStore 存值
- Entity data class（Room）
- data class + Retrofit interface @GET、suspend
- loadWeather + try/catch，跑公開 API 印出資料 ★
- LaunchedEffect + state 在 Compose 顯示（對應 SwiftUI .task）
