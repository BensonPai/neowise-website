C# 程式設計完整教學 🐾

從零開始學 C#，一條循序漸進的路徑，帶你從語法基礎走到實戰應用

想學 C#，卻被滿坑滿谷的教學搞得更亂？這個系列把 C# 從頭到尾鋪成一條路：先裝好環境、打穩語法基礎，再進入物件導向與進階主題，最後用實戰專案把學到的串起來。

走的是「循序漸進、重觀念」路線。建議從第一篇環境準備開始照順序走；每個主題都盡量用能動手跑的小範例說明。每篇文章底部都有系列導覽連結。

※ 文中版本、工具與 API 均標註查證時間，實際請以 .NET / Microsoft Learn 官方文件為準。

總覽先看全貌

一篇看懂 C# 能做什麼、要裝什麼、這個系列會帶你走到哪。

  1. 總

    C# 是什麼、能做什麼？從零開始的學習地圖

    想學 C# 卻不知道從何下手？這篇一次講清楚 C# 是什麼、能做哪些東西（桌面、Web、遊戲、後端）、要裝什麼工具，並給你一張從語法基礎到實戰專案的完整學習路徑，當作整個 C# 教學系列的入口。

基礎語法基礎

變數與型別、流程控制、方法與例外處理，打穩寫 C# 的地基。

  1. 1

    開發環境準備：安裝 .NET SDK 與 Visual Studio，跑出第一支程式

    學 C# 的第一關是把環境裝好。這篇手把手帶你安裝 .NET SDK、選擇 Visual Studio 或 VS Code、建立第一個主控台專案，並跑出經典的 Hello World，踏出 C# 開發扎實的第一步。

  2. 2

    語法基礎：變數、型別、運算子與流程控制

    環境裝好後，就從 C# 語法基礎開始動手寫。這篇用實際範例帶你搞懂變數與常數、常見資料型別、運算子，以及 if、switch、for、while 等流程控制，打好寫 C# 的地基。

  3. 3

    方法與例外處理：把程式切成好用的小塊，並優雅地處理錯誤

    程式變長就該拆成方法。這篇帶你搞懂 C# 的方法：參數、回傳值、多載與預設參數，再學會用 try/catch/finally 處理例外，讓程式遇到錯誤也不會整個崩掉。

OOP物件導向

類別與物件、封裝繼承多型、介面與泛型，寫出結構良好的程式。

  1. 4

    類別與物件：物件導向的第一步

    C# 是物件導向語言，而類別是它的核心。這篇帶你從零認識類別與物件：欄位、屬性、方法、建構式，以及 new 一個物件到底發生了什麼事，為後面的封裝繼承多型打底。

  2. 5

    封裝、繼承、多型：物件導向的三大支柱

    學會類別之後，這篇進入物件導向的核心三支柱：封裝（藏好細節）、繼承（複用與擴充）、多型（同一介面不同行為）。用好懂的範例帶你理解它們解決了什麼問題。

  3. 6

    介面與泛型：寫出更有彈性、可重用的程式

    這篇帶你認識 C# 的介面（interface）與抽象類別：怎麼定義「一份契約」，以及泛型（generics）如何讓同一段程式適用多種型別，寫出又彈性又安全的程式碼。

進階進階主題

集合與 LINQ、非同步、檔案與資料存取等實用進階主題。

  1. 7

    集合與 LINQ：優雅地處理一堆資料

    實務上你常要處理「一堆資料」。這篇帶你認識 C# 常用集合 List、Dictionary，再學 LINQ：用接近自然語言的寫法做篩選、排序、投影與統計，讓資料處理又短又好讀。

  2. 8

    非同步 async/await：讓程式不卡頓

    下載檔案、呼叫 API 時程式會「卡住」等結果？這篇用白話帶你理解 C# 的非同步：為什麼需要 async/await、Task 是什麼、怎麼寫出不凍結、能同時做多件事的程式。

  3. 9

    檔案讀寫與 JSON：讓程式能存資料、讀資料

    程式關掉資料就不見？這篇帶你用 C# 做檔案讀寫，並認識怎麼把物件轉成 JSON 存檔、再讀回來，讓你的程式真正能記住東西，為實戰專案做準備。

實戰實戰專案

把前面學到的整合起來，做出一個完整的小專案。

  1. 10

    實戰專案：動手做一個主控台待辦清單 App

    學了這麼多，這篇把全部串起來：用 C# 從零做一個可以新增、檢視、完成、刪除、並能存檔讀檔的主控台待辦清單程式，實際體會類別、集合、LINQ、檔案與例外處理怎麼協作。
