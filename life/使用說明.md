# 智慧喵部落格 使用說明

這是獨立於炘智科技 B2B 網站的個人生活部落格，位於 `neowise.com.tw/life/`。
定位：理財、旅遊、生活分享，並行銷自己開發的軟體。與炘智的部落格分開運作。

---

## 資料夾結構

```
neowise-website/life/
├── index.html              ← 文章列表（自動產生）
├── <slug>.html             ← 各篇文章（自動產生）
├── tools.html              ← 我的工具（手動維護）
├── about.html              ← 關於（手動維護）
├── style.css               ← 智慧喵專屬風格
├── build-life.bat          ← 雙擊執行產生器
├── sitemap.xml             ← 自動產生
├── content/                ← 文章原始碼（Markdown）
│   ├── _drafts/            ← 草稿、待審核
│   └── _published/         ← 已發布歸檔（可選）
├── scripts/build-life-blog.mjs   ← 產生器
└── assets/<slug>/          ← 各篇圖片
```

> `index.html` 與各文章 `.html` 都是自動產生的，別手動改。要改內容改 `content/` 的 `.md`。
> `tools.html`、`about.html` 是手刻頁，要改直接編輯。

## 發文流程

1. **產文**：在 Kiro 對話裡給題目（例如「寫一篇旅遊工具的文章」），我在 `content/_drafts/` 產出 `.md`。
2. **審核**：打開草稿檢視，要改跟我說。通過後把 `status` 改成 `approved`。
3. **配圖**：依 `.md` 的 images 清單，把圖放到 `life/assets/<slug>/`（檔名一致）。缺圖可先發，之後補。
   - 注意：`images` 清單只是「配圖需求」。**第一張會自動當封面顯示在文章頂部；其餘內文圖必須在正文用 `![說明](assets/<slug>/檔名.jpg)` 插入才會顯示。** Kiro 產文時應直接在正文插好內文圖，別只留在 images 清單。
4. **產生**：雙擊 `build-life.bat`（或 `node scripts/build-life-blog.mjs`）。
5. **上傳**：用 GitHub Desktop 同步 `neowise-website`，GitHub Pages 會自動更新。

## 文章格式（front-matter）

```markdown
---
title: "文章標題"
description: "摘要（卡片與 SEO 用）"
keywords: ["關鍵字1", "關鍵字2"]
slug: "url-用英文與連字號"
date: "2026-09-17"
author: "智慧喵"
category: "投資理財"      # 投資理財 / 科技 / 旅遊 / 生活
status: "draft"           # draft=不發布，approved=會發布
order: 1                  # 選填：同日期多篇時的排序（數字小的排前面），系列文章建議填篇號
youtube: ""               # 選填：YouTube 影片ID或網址，有值文章頁會自動嵌入播放器
youtube_title: ""         # 選填：影片標籤顯示的名稱，沒填則顯示「影片版」
cover_alt: "封面圖說明"
images:
  - file: "cover.jpg"     # 一律 jpg
    alt: "封面圖說明"
    prompt: "生圖提示"
---

## 小標題
正文（支援粗體、清單、引用、表格、連結、圖片）
```

## 分類

- **投資理財**（靛紫標籤，`invest`）
- **科技**（青藍標籤，`tech`）：最新科技、程式寫作、資訊產品使用。見「科技寫作框架.md」。
- **旅遊**（藍色標籤，`travel`）
- **生活**（暖色標籤，`life`）：健康美食、生活技巧、心情故事。見「生活寫作框架.md」。

> 原本的「理財」分類已移除，併入「投資理財」（記帳等純理財主題也歸這類）。

首頁上方有分類篩選按鈕，訪客可切換只看某類文章。分類寫死在產生器的 `CAT_CLASS`、首頁篩選按鈕與導覽列；要新增分類需同步改這三處與 `style.css` 的 `.post-tag.<class>`。

## 投資理財修煉系列

「投資理財」分類主要承載「**智慧喵的投資理財修煉**」系列——一個由淺入深的投資學習記錄，分三階段：

- **入門篇**：理財心法（基本概念、投資心態）
- **進階篇**：投資招式（各種工具、技術面／基本面／籌碼面／財務面分析）
- **高手篇**：財務自由修煉（被動收入、全球視野、AI 投資工具）

規則與慣例：
- 系列文章 `category` 都設 `"投資理財"`，標題掛前綴 `【投資理財修煉·入門篇/進階篇/高手篇】`。
- 系列文章建議填 `order`（= 篇號）。首頁主要照日期排（新到舊），**同日期多篇時才用 order 決定順序**（數字小的排前面）。這樣就算同一天發多篇，順序也不會亂。延伸閱讀（如富爸爸書介）可用小數（如 3.5）插在篇號之間。
- 排序採 **A+B**：文章底部放「回系列目錄／下一篇」導覽連結，並維護一頁**系列目錄** `life/invest.html`（手刻頁，新增文章時要在目錄頁補上連結、把「即將推出」改成正式連結）。
- 定位是**學習記錄／知識整理，非投資建議**；每篇結尾放免責聲明。談權證、期貨等高槓桿工具時，重點放風險，不報明牌、不給買賣建議。
- 想加新文章（例如補充某個技術指標）：直接多加一個 `.md` 即可，數量不限；記得更新 `invest.html` 目錄與前後篇連結。

## 聯盟行銷廣告（`::aff::` 語法）

在文章 Markdown 裡**自成一行**寫 `::aff ...::`，跑產生器時會自動展開成置中、手機不破版、附揭露聲明與 `rel="sponsored"` 的廣告區塊。改揭露文字或 AP 代號，統一在 `scripts/build-life-blog.mjs` 最上方的 `AP_ID` 與 `AFF_NOTE` 調整，全站一次生效。

**用法一：博客來（最簡單，直接貼商品連結）**

```
::aff https://www.books.com.tw/products/0010935466::
```

- 預設是直式**高版**貼紙，標題自動帶「📖 想入手這本書」。
- 想改**寬版**、或自訂標題，在連結後面加參數：
```
::aff https://www.books.com.tw/products/0010935466 wide 這本我超推::
```
- 系統會自動補上你的 AP 代號與追蹤參數，你貼原始商品連結就行。

**用法二：博客來（參數式，只有商品編號時）**

```
::aff books 0010935466 high 📖 想入手這本書::
```
- 格式：`books <10碼商品編號> [high|wide] [標題文字]`
- `high` = 直式高版（`/0/7`）、`wide` = 橫式寬版（`/1/3`），不填預設 high。

**用法三：momo／蝦皮／一般合作連結（按鈕式）**

```
::aff link https://範例連結 | 看看這個工具 | 自訂揭露文字（可省略）::
```
- 第一段是連結，第二段是按鈕文字，第三段（可省）是自訂揭露聲明。
- 平台可用 `link`、`momo`、`shopee`，會各自帶對應的預設揭露文字。
- momo／蝦皮請直接貼你在聯盟平台拿到的推廣連結（已含你的分潤參數）。

**用法四：Hahow 好學校（整個平台共用一條連結）**

Hahow 的聯盟連結是「整個平台一條通用連結」，不是每堂課各自的連結。所以連結已內建在腳本裡，文章不用貼連結，直接呼叫即可：

```
::aff hahow::
```
- 全省略時用預設文案（標題＋說明＋按鈕）。
- 可自訂文字，用 `|` 分三段：`標題 | 說明文字 | 按鈕文字`（後兩段可省）：
```
::aff hahow 想學 App 開發？ | 從 Kotlin 到上架，Hahow 有完整實作課::
```
- **連結在哪改**：腳本頂端 `HAHOW_URL` 常數（目前已設定為 `https://joymall.co/3Tker`）。日後換連結只改這一處，全站生效。
- **措辭原則**：因為連結只到平台（非特定課程頁），按鈕請用「到 Hahow 看看／逛逛」這類字眼，不要寫「立即購買這堂課」，避免誤導讀者。想推特定課程時，在內文寫課名與心得，但連結仍導向平台、請讀者自行搜尋。

**用法五：KKday 旅遊行程（動態商品廣告，適合旅遊文章）**

KKday 這類是「靠 JavaScript 動態渲染」的廣告，會自動輪播旅遊行程／體驗，你不用自己挑商品。語法：

```
::aff kkday::
```
- 預設顯示 3 個商品。想改數量就加數字：
```
::aff kkday 4::
```
- **腳本自動只載一次**：那支 `iframe.init.1.0.js` 無論一頁放幾個 `::aff kkday::`，產生器都只會在頁尾注入一次，你不用管。
- **要連網才看得到**：廣告內容是線上腳本即時抓的，本機離線預覽會是空白區塊，屬正常現象。
- 放置建議：旅遊文章的「行程總覽」後、或文末「怎麼訂」的段落最自然。

**注意**：`::aff::` 必須單獨成一行，前後各空一行，才會被辨識為廣告區塊。解析失敗時會在 HTML 留一行註解提示（不會中斷產生）。

## 與炘智部落格的差異

| | 炘智部落格 | 智慧喵部落格 |
|---|---|---|
| 位置 | `/blog/` | `/life/` |
| 風格 | 深色科技風 | 淺色清新風 |
| 產生器 | `build-blog.bat` | `build-life.bat` |
| 內容 | 機器視覺 B2B | 理財/旅遊/生活 |

兩者完全獨立，各自產生、各自的 sitemap，互不影響。
