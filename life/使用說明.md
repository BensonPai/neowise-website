# 智慧喵部落格 使用說明

這是獨立於炘智科技 B2B 網站的個人生活部落格，位於 `neowise.com.tw/life/`。
定位：理財、旅遊、生活分享，並行銷自己開發的軟體。與炘智的部落格分開運作。

---

## 資料夾結構

```
neowise-website/life/
├── index.html              ← 文章列表（自動產生）
├── <slug>.html             ← 各篇文章（自動產生）
├── tools.html              ← 我的工具（手動維護）
├── about.html              ← 關於（手動維護）
├── style.css               ← 智慧喵專屬風格
├── build-life.bat          ← 雙擊執行產生器
├── sitemap.xml             ← 自動產生
├── content/                ← 文章原始碼（Markdown）
│   ├── _drafts/            ← 草稿、待審核
│   └── _published/         ← 已發布歸檔（可選）
├── scripts/build-life-blog.mjs   ← 產生器
└── assets/<slug>/          ← 各篇圖片
```

> `index.html` 與各文章 `.html` 都是自動產生的，別手動改。要改內容改 `content/` 的 `.md`。
> `tools.html`、`about.html` 是手刻頁，要改直接編輯。

---

## 發文流程

1. **產文**：在 Kiro 對話裡給題目（例如「寫一篇旅遊工具的文章」），我在 `content/_drafts/` 產出 `.md`。
2. **審核**：打開草稿檢視，要改跟我說。通過後把 `status` 改成 `approved`。
3. **配圖**：依 `.md` 的 images 清單，把圖放到 `life/assets/<slug>/`（檔名一致）。缺圖可先發，之後補。
4. **產生**：雙擊 `build-life.bat`（或 `node scripts/build-life-blog.mjs`）。
5. **上傳**：用 GitHub Desktop 同步 `neowise-website`，GitHub Pages 會自動更新。

## 文章格式（front-matter）

```markdown
---
title: "文章標題"
description: "摘要（卡片與 SEO 用）"
keywords: ["關鍵字1", "關鍵字2"]
slug: "url-用英文與連字號"
date: "2026-09-17"
author: "智慧喵"
category: "理財"          # 理財 / 旅遊 / 生活
status: "draft"           # draft=不發布，approved=會發布
cover_alt: "封面圖說明"
images:
  - file: "cover.png"
    alt: "封面圖說明"
    prompt: "生圖提示"
---

## 小標題
正文（支援粗體、清單、引用、表格、連結、圖片）
```

## 分類

- **理財**（薄荷綠標籤）
- **旅遊**（藍色標籤）
- **生活**（暖色標籤）

首頁上方有分類篩選按鈕，訪客可切換只看某類文章。

---

## 圖片來源

- 照片：Unsplash / Pexels / Pixabay（搜英文關鍵字）
- 生圖：Google AI Studio（貼 images 裡的 prompt）
- 資訊圖：Canva

生活風建議用溫暖明亮的照片，跟薄荷綠的清新風格搭。

---

## 與炘智部落格的差異

| | 炘智部落格 | 智慧喵部落格 |
|---|---|---|
| 位置 | `/blog/` | `/life/` |
| 風格 | 深色科技風 | 淺色清新風 |
| 產生器 | `build-blog.bat` | `build-life.bat` |
| 內容 | 機器視覺 B2B | 理財/旅遊/生活 |

兩者完全獨立，各自產生、各自的 sitemap，互不影響。
