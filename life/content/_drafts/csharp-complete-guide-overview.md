「我想學程式，聽說 C# 不錯……可是它到底能做什麼？從哪裡開始學？」

如果你心裡冒出過這個問題，這篇就是為你寫的。網路上 C# 教學一大堆，但往往一上來就叫你打開 Visual Studio、貼一段看不懂的程式。這篇先不急著寫 code，而是帶你把整張地圖看清楚：**C# 是什麼、能做哪些東西、要裝什麼、以及這個系列會怎麼帶你一步步學。**

這是「C# 教學」系列的入口。後面我規劃的是一條**循序漸進、重觀念**的路，不是把語法硬塞給你，而是讓你每一步都知道「學這個是為了做什麼」。

## 一、C# 是什麼？

C#（讀作 C-Sharp）是微軟在 2000 年推出的程式語言，跑在 **.NET** 這個平台上。它的定位是「現代、好讀、功能完整」的通用語言——語法乾淨、工具成熟，而且背後有微軟長期維護，學了不怕過時。

幾個它的特色，用白話說：

- **強型別**：變數是什麼型別要講清楚，雖然一開始多打幾個字，但編譯器會幫你擋掉很多低級錯誤。
- **物件導向**：天生就是為「用類別組織程式」設計的，學會它對理解很多現代語言都有幫助。
- **跨平台**：現在的 .NET 不只在 Windows 跑，macOS、Linux 都行。
- **生態完整**：從做視窗程式、網站、手機 App 到遊戲，幾乎都有對應的框架。

## 二、C# 能做什麼？

這是最多人好奇的地方。學會 C#，你可以做這些：

| 領域 | 用的技術 | 做出來的東西 |
|------|---------|------------|
| 桌面應用程式 | WPF、WinForms、MAUI | Windows 視窗軟體、工具程式 |
| 網站與後端 | ASP.NET Core | 網站、Web API、後端服務 |
| 遊戲開發 | Unity | 2D／3D 遊戲（Unity 用 C# 寫腳本） |
| 跨平台 App | .NET MAUI | 一套程式碼跑 Windows／Android／iOS |
| 雲端與服務 | Azure Functions 等 | 雲端服務、自動化後端 |

換句話說，C# 不是只能做某一種東西的語言。它是那種「學會之後，很多方向都能走」的通用底子。對初學者特別友善的一點是：**Unity 遊戲開發用的就是 C#**，如果你是想做遊戲入門的，學 C# 一舉兩得。

## 三、學 C# 要裝什麼？

好消息是：全部免費，而且任何一台還算堪用的電腦都能開始。你需要兩樣東西。

**1. .NET SDK**

這是 C# 的「開發套件」，包含編譯器與執行環境。沒有它，程式沒辦法跑。到 .NET 官方網站下載安裝即可，Windows、macOS、Linux 都有。

**2. 一個編輯器 / IDE（二選一）**

- **Visual Studio**（Windows / Mac）：微軟官方的大型開發工具，功能最完整，有免費的 Community 版。新手我會先推這個，因為它把編譯、除錯、提示整合得最好。
- **Visual Studio Code**：輕量編輯器，裝上 C# 擴充套件也能寫，跨平台、開得快。習慣輕量工具的人會喜歡。

> 這兩個名字很像，別搞混：**Visual Studio** 是完整 IDE，**Visual Studio Code** 是輕量編輯器，是兩個不同的軟體。環境怎麼裝，下一篇會手把手帶。

## 四、這個系列會帶你走到哪

我把 C# 的學習路徑分成五個階段，一階一階往上疊：

1. **總覽**（就是這篇）：先看懂全貌，知道自己在學什麼。
2. **語法基礎**：變數與型別、流程控制、方法、例外處理——寫任何 C# 程式的地基。
3. **物件導向**：類別與物件、封裝繼承多型、介面與泛型，學會用結構良好的方式組織程式。
4. **進階主題**：集合與 LINQ、非同步 async/await、檔案與資料存取等實用技能。
5. **實戰專案**：把前面學到的全部串起來，做一個完整的小專案收尾。

建議就從頭照順序走。程式這種東西，地基沒打穩，後面會越學越吃力；反過來說，基礎紮實了，後面會越學越快。

## 五、給初學者的三句真心話

最後，分享幾句我自己學程式的體會：

- **別怕看不懂，先動手跑**。程式是「做中學」的東西，讀十遍不如自己打一次、按下執行看結果。
- **錯誤訊息是朋友，不是敵人**。C# 的編譯器會告訴你哪裡錯、為什麼錯，看懂它比什麼都重要。
- **慢就是快**。不用急著追進度，每個概念真的懂了再往下，整體反而學得更快更穩。
