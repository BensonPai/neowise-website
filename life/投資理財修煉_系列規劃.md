> 這份是「投資理財修煉」系列的總規劃，開新對話要接續寫這系列時，先讀這份即可掌握全貌。

---

## 系列定位

- **名稱**：智慧喵的投資理財修煉
- **性質**：個人投資學習記錄／知識整理，**非投資建議**。
- **分類**：所有文章 `category` 設 `"投資理財"`（靛紫標籤，class = `invest`）。
- **風格**：由白話切入，逐步深入到實作。親切、清楚，跟智慧喵一貫口吻一致。
- **目錄頁**：`life/invest.html`（手刻頁，當系列入口）。

### 重要原則（合規與風險）

- 定位是「學習記錄／知識整理」，不是報明牌、不給買賣建議、不喊目標價。
- 講權證、期貨等高槓桿工具時，**重點放風險**。
- 每篇結尾放免責聲明：「本文為個人學習記錄與知識整理，非投資建議。投資有風險，請依自身情況獨立判斷 🐾」。

## 每篇文章寫作模板

**front-matter**
```yaml
title: "【投資理財修煉·入門篇】文章標題"   # 前綴依階段換：入門篇/進階篇/高手篇
description: "..."
keywords: [...]
slug: "invest-xxx"
date: "YYYY-MM-DD"
author: "智慧喵"
category: "投資理財"
status: "approved"          # 這系列預設 approved，確認後再上網站
cover_alt: "..."
images:
  - file: "cover.jpg"       # 一律 jpg
    ...
```

**正文結構（由白話到深入）**
1. 開場：生活化情境或問題切入（並點出這是系列第幾篇／哪個階段）
2. 白話說明：這是什麼、為什麼重要
3. 深入：實作方法、關鍵細節、圖表（進階／高手篇更深）
4. 風險與提醒
5. 系列導覽區塊（見下）
6. 免責聲明

**系列導覽區塊（放正文最後、免責聲明之前）**
```markdown
---

**系列導覽**

- 📚 回到 [投資理財修煉 全系列目錄](invest.html)
- ⬅️ 上一篇：（標題）(上一篇slug.html)
- ➡️ 下一篇：（標題）(下一篇slug.html)   # 未發布就寫「（即將推出）」

> 本文為個人學習記錄與知識整理，非投資建議。投資有風險，請依自身情況獨立判斷 🐾
```

## 發新文章的流程（這系列專屬）

1. 依模板在 `life/content/_drafts/` 產出 `.md`，`status` 直接設 `approved`。
2. 內文圖記得**直接插進正文**（`![](assets/<slug>/xxx.jpg)`），不要只留在 images 清單。
3. 更新目錄頁 `life/invest.html`：把該篇從「（即將推出）」改成正式連結（`<li class="toc-item pending">` 去掉 pending、加上 `<a href>`）。
4. 更新前一篇文章的「下一篇」連結（從「即將推出」改成正式連結）。
5. 跑 `build-life.bat` 產生。
6. 確認沒問題後用 GitHub Desktop 上網站。

## 圖片慣例（沿用全站規則）

- 格式一律 jpg；封面約 1200x630、資訊圖約 1000x1000，不超過 1600px 寬（產生器會自動縮）。
- 資訊圖（圓餅圖、金字塔、比較表、流程圖）建議用 Canva 做，最清楚。
- 放進 `life/assets/<slug>/`，檔名與 front-matter 一致。
