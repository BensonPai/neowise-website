Python 程式設計完整教學 🐾

從零開始學 Python，從語法基礎到資料處理、自動化與實戰，一條好上手的學習路徑

想學程式，很多人第一個推薦就是 Python——語法乾淨、好上手、用途又廣。這個系列把 Python 從頭鋪成一條路：先裝好環境、打穩語法與資料結構，再進物件導向，接著學 Python 最強的「實用應用」（檔案處理、爬蟲、自動化、資料分析），最後用實戰專案收尾。

走的是「循序漸進、重實用」路線。建議從第一篇環境準備照順序走；每個主題都用能動手跑的小範例說明。每篇文章底部都有系列導覽連結。

※ 文中版本、套件與 API 均標註查證時間，實際請以 Python 官方文件與各套件文件為準。

總覽先看全貌

一篇看懂 Python 能做什麼、要裝什麼、這個系列會帶你走到哪。

  1. 總

    Python 是什麼、能做什麼？從零開始的學習地圖

    想學程式、聽說 Python 最好上手？這篇一次講清楚 Python 是什麼、能做哪些事（自動化、爬蟲、資料分析、AI、後端）、要裝什麼工具，並給你一張從語法基礎到實戰的完整學習路徑，當作整個 Python 教學系列的入口。

基礎語法基礎

變數與型別、流程控制、函式，以及 list、dict 等資料結構，打穩地基。

  1. 1

    開發環境準備：安裝 Python、VS Code，跑出第一支程式

    學 Python 的第一關是把環境裝好。這篇手把手帶你安裝 Python、設定 VS Code、認識 pip 套件安裝器，並跑出第一支程式，踏出 Python 開發扎實的第一步。

  2. 2

    語法基礎：變數、型別、流程控制與縮排規則

    環境裝好後，就從 Python 語法基礎開始動手寫。這篇帶你搞懂變數與型別、運算子、if/for/while 流程控制，以及 Python 最特別的「用縮排表示程式區塊」規則，打好地基。

  3. 3

    函式：把程式切成好用的小塊

    程式變長就該拆成函式。這篇帶你搞懂 Python 的函式：用 def 定義、參數與回傳值、預設參數，以及 *args / **kwargs 入門，讓程式有條理、可重用。

  4. 4

    資料結構：list、tuple、dict、set 一次搞懂

    Python 最常用的四種資料結構：list（清單）、tuple（元組）、dict（字典）、set（集合）。這篇帶你搞懂它們各自怎麼用、差在哪、什麼時候用哪個，還有好用的推導式。

OOP物件導向

類別與物件、繼承與特殊方法，寫出結構良好的程式。

  1. 5

    類別與物件：用物件的方式組織程式

    這篇帶你認識 Python 的物件導向：用 class 定義類別、__init__ 建構式、屬性與方法、self 是什麼，從零學會「用物件思考」組織程式。

  2. 6

    繼承與特殊方法：讓類別更強大

    學會類別之後，這篇進入繼承（複用與擴充）與 Python 的特殊方法（dunder methods，如 __str__）：讓你的類別能被 print 得漂亮、能用運算子，寫出更 Python 風格的程式。

應用實用應用

Python 的強項：檔案與 JSON、網路爬蟲、自動化、資料處理入門。

  1. 7

    檔案讀寫與 JSON：讓程式能存資料、讀資料

    程式關掉資料就不見？這篇帶你用 Python 做檔案讀寫（open、with），並用內建 json 模組把資料存成 JSON、再讀回來，讓程式真正能記住東西。

  2. 8

    網路爬蟲入門：用 requests + BeautifulSoup 抓網頁資料

    Python 最受歡迎的應用之一就是爬蟲。這篇帶你用 requests 抓網頁、用 BeautifulSoup 解析內容，從零學會自動抓取網頁資料，並說明禮貌爬取與法律界線。

  3. 9

    自動化腳本：把重複的工作交給程式

    每天重複做的瑣事，用 Python 自動化。這篇帶你用 Python 批次處理檔案、整理資料夾、做簡單的定時任務，體會「寫一次、省一輩子」的自動化威力。

  4. 10

    資料處理入門：用 pandas 讀 CSV、篩選、統計

    Python 在資料分析界是王者。這篇帶你入門 pandas：讀取 CSV、檢視與篩選資料、做基本統計，還有畫出簡單圖表，體會用程式處理資料的威力。

實戰實戰專案

把前面學到的整合起來，做出一個完整的小工具。

  1. 11

    實戰專案：做一個檔案整理小工具

    學了這麼多，這篇把全部串起來：用 Python 做一個能自動整理資料夾的命令列小工具，實際體會語法、函式、資料結構、檔案操作怎麼協作成一個真正能用的程式。
