# 智慧喵 生活文章 寫作框架

> 開新對話要寫生活文章時，先讀這份即可掌握範圍與風格。生活不做線性系列、不做目錄頁，跟投資理財修煉不同，比照旅遊採輕量框架。

---

## 核心原則

- **分類固定為「生活」**（暖色標籤 `life`）：四個主題方向只是「寫作方向」，不另做子分類、不加篩選按鈕。用標題自然標示主題即可。
- **不做系列、不做目錄頁**：文章自由散落在「生活」分類，靠首頁篩選按鈕找。
- **想寫才寫**：沒有進度壓力。
- **軟體導流自然就好**：相關時再帶到自製軟體（尤其「科技與工具」類），不強求每篇都連。

---

## 四個主題方向

生活文章圍繞這四個方向，涵蓋理性到感性：

1. **科技與工具**：App、軟體、3C、數位工具、自動化。
   - 天生適合自然帶到智慧喵的自製軟體（進銷存、財務管理、股票投資分析、任務追蹤、iPhone 相片備份）。
   - 例：好用的待辦 App、手機檔案整理、用工具自動化生活。
2. **健康與美食**：飲食、運動、料理、養生、外食心得。
   - 例：在家簡單料理、健康習慣、我常吃的幾家店。
3. **生活技巧**：整理、收納、效率、日常小撇步。
   - 例：桌面整理術、數位斷捨離、省時小技巧。
4. **心情故事**：隨筆、感想、生活觀察——最有個人溫度的一類。
   - 例：一段生活體悟、某件事的心得、慢下來的觀察。

> 用標題自然標示主題，例如「【生活技巧】…」「【心情】…」，或直接讓標題點出主題，不強制格式。

---

## 結構（依主題彈性調整）

生活文章不像旅遊有固定五段式，依主題彈性處理，但盡量掌握：

- **開場**：一個生活化的情境或問題切入，讓讀者有共鳴。
- **主體**：
  - 科技與工具／生活技巧 → 偏「怎麼做、實用步驟、清單、比較」。
  - 健康與美食 → 偏「心得、做法、推薦」。
  - 心情故事 → 偏「敘事、感受、觀察」，結構最自由。
- **收尾**：一句心得或行動建議；相關時自然帶軟體或 YouTube，用 🐾 收。

## front-matter 範本

```yaml
title: "文章標題（可在標題點出主題）"
description: "..."
keywords: [...]
slug: "英文-連字號"
date: "YYYY-MM-DD"
author: "智慧喵"
category: "生活"
status: "approved"
cover_alt: "..."
images:
  - file: "cover.jpg"       # 一律 jpg
    ...
```

---

## 寫作與配圖注意

- **內文圖要插進正文**（`![](assets/<slug>/xxx.jpg)`），別只留在 images 清單，否則不顯示。第一張自動當封面。
- 格式一律 jpg；封面約 1200x630、內文約 1200x800，不超過 1600px 寬（產生器會自動縮）。
- 語氣：親切、真實、白話，跟智慧喵一貫口吻一致。心情故事類可以更放鬆、更個人。

---

## 發文流程

1. 給主題 → 依此框架在 `life/content/_drafts/` 產出 `.md`（`status` 直接 approved）。
2. 配圖放進 `life/assets/<slug>/`（缺圖可先發）。
3. 跑 `build-life.bat` 產生。
4. 確認沒問題後用 GitHub Desktop 上網站。

（生活不需更新任何目錄頁或前後連結，比投資理財系列單純。）
